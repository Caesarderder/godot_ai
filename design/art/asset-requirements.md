# 《灰镜战线》美术素材需求

> 状态：执行基线 v1
> 目标平台：Godot 4.6.3 / Web / Compatibility / 手机横屏 844×390
> 更新日期：2026-07-27
> 关联规范：[UI 视觉刷新](../ux/slg-ui-visual-refresh.md)、[素材管理方案](../../project-a/assets/ASSET_MANAGEMENT.md)

## 1. 目标与边界

本轮素材不是给现有界面增加装饰，而是解决三个明确问题：

1. 用统一图标降低资源、战斗状态和操作入口的文字识别成本；
2. 用少量工业/城市环境素材增强“地下工厂支援地表攻城”的空间叙事；
3. 保留现有瓷甲角色的独特轮廓，补齐材质、动画和阵营辨识，而不是用通用角色包替换核心人物。

视觉命题：

> 焦黑工业承载面 + 瓷质角色轮廓 + 冷青机械回应 + 暖橙战争警戒。

禁止项：

- 不使用来源不明、仅标注“free”但无许可证的素材；
- 不使用需要登录、付费、订阅或限制商业使用的素材作为本轮依赖；
- 不引入写实 PBR 人物、像素 UI、卡通糖果 UI 等与现有低模工业风冲突的包；
- 不把第三方素材原样大批导入；只保留实际使用或已排期的最小子集；
- 不用颜色单独表达资源、危险、完成或禁用状态。

## 2. 当前视觉基线

| 项目事实 | 当前状态 | 素材影响 |
|---|---|---|
| 基准画布 | 844×390 横屏，触屏优先 | 图标必须在 20–32 px 仍有强剪影；按钮触区不小于现有 44–48 px |
| UI 语言 | 深蓝黑面板、青/金/红/绿语义色、Noto Sans CJK SC | 首选单色或易着色图标，不引入另一套面板皮肤 |
| 工厂世界 | 低模 3D 岛与六座可点击设施 | 补工业道具与地表材质，不遮挡建筑点击轮廓 |
| 战斗世界 | 低模灰城、三路推进、瓷质敌我单位 | 补路障、路灯、箱体等轮廓道具，保持道路和敌人清晰 |
| 角色 | 8 个现有 GLB 外观 + 程序化瓷质本体 | 先治理现有模型与动画，不替换为通用人形角色 |
| Web 约束 | Compatibility、移动浏览器、初始包体敏感 | GLB、PNG/WebP 优先；控制纹理尺寸和模型面数 |

## 3. 需求优先级

### P0：统一 UI 图标

| 资产族 | 语义清单 | 技术规格 | 使用位置 | 验收 |
|---|---|---|---|---|
| 工业资源 | 陶瓷、零件、能源、金币、技术 | PNG，透明背景；源图建议 64×64；运行尺寸 20/24 px | 顶部库存、奖励、成本、结算 | 25% 缩放仍能按轮廓区分；配数字时不跳布局 |
| 导航 | 工厂、战区、军团、行动、设置/档案 | PNG，透明背景；64×64 源图 | 底部导航、标题页安静操作 | 未选/选中同时使用图标、文字、描边 |
| 战斗状态 | 生命、护盾、能量、自动技能、暂停、撤退、Boss | PNG，透明背景；64×64 源图 | 战斗 HUD、战前与结算 | 20 px 可读；危险与奖励不共享同一轮廓 |
| 操作反馈 | 建造、升级、收取、研究、编队、出击 | PNG，透明背景；64×64 源图 | CTA 前导图标、上下文提示 | 图标只负责分类，首次出现保留中文短标签 |

选择策略：优先一套 CC0、同网格、同描边/填充规则的完整图标包；只选取约 24–36 个实际图标并建立语义映射，不混用多套图标。

### P1：3D 环境模块

| 资产族 | 最小需求 | 技术规格 | 使用位置 | 性能/视觉约束 |
|---|---|---|---|---|
| 城市战场道具 | 路障、交通锥、路灯、箱体、护栏、废料 | GLB/glTF 优先；单件可独立实例化 | 战斗道路边缘、掩体带 | 单屏新增三角面预算建议 ≤ 25k；不得缩窄三路读图 |
| 工厂道具 | 管线、储罐、货盘、机械箱、警示灯 | GLB/glTF 优先 | 工厂岛外围与设施附近 | 不覆盖建筑可点击轮廓；青/橙光只做局部强调 |
| 地表材质 | 沥青、混凝土、金属板、警戒线 | 可平铺 PNG；建议 512 或 1024；有 mipmap | 战斗道路、工厂平台 | Compatibility 下无强依赖高阶 Shader；移动端无明显闪烁 |

选择策略：优先同一低模城市/工业套件；环境道具作为构图语言，不以“资产数量”填满画面。

### P1：现有 3D 人物提升

本项以现有 `porcelain-raider-kit` 为基础，不采购替换角色。

| 需求 | 规格 | 验收 |
|---|---|---|
| 来源与许可治理 | 为现有 8 个 GLB 补齐可发布的 provenance、许可状态和哈希 | 未知权利不得进入正式发布 |
| 材质分层 | 瓷白主体、阵营色辅件、危险/技能发光三层 | 灰度下仍靠轮廓和明度识别敌我 |
| 基础动画 | idle、attack、hit、skill、defeat；可由程序动画与骨骼动画组合 | reduced motion 有稳定降级；攻击方向可读 |
| 角色图标/肖像 | 每个永久角色一张一致视角的半身或轮廓图 | 军团页 48–72 px 可区分，不直接使用 3D 截图的杂乱背景 |
| LOD/包体 | 每个主角模型记录三角面、纹理与 GLB 大小 | 基准战斗峰值不因角色升级产生明显掉帧 |

### P2：氛围与品牌层

- 标题页工厂剪影或信号噪声背景；
- 章节地图的城镇轮廓标记；
- 胜利、失败、研究突破的克制徽章；
- 可复用的警戒条纹、铆钉、瓷裂纹等小型纹理。

P2 不得先于 P0 图标和 P1 环境验收进入实现。

## 4. UI 语义映射

| 游戏语义 | 首选图形母题 | 颜色职责 | 禁止混淆 |
|---|---|---|---|
| 陶瓷 | 碎片/六边瓷片 | 中性米白 | 不用盾牌 |
| 零件 | 齿轮/螺母 | 暖灰/铜 | 不用金币 |
| 能源 | 闪电/电池 | 冷青 | 不用技能星芒 |
| 金币 | 硬币堆 | 金色 | 不用技术芯片 |
| 技术 | 芯片/烧瓶 | 青绿 | 不用设置齿轮 |
| 工厂 | 厂房/烟囱 | 青色选中 | 不用城市天际线 |
| 战区 | 准星/地图节点 | 橙红风险 | 不用设置罗盘 |
| 军团 | 三人编队/头盔 | 米白主体 | 不用单人头像 |
| 行动 | 旗帜/任务章 | 金色机会 | 不用成就奖杯 |

最终映射写入素材 manifest；若素材包没有合适图形，宁可保留文字，也不使用语义错误的近似图标。

## 7. 验收场景

1. 标题页：图标不能抢过剧情主 CTA；
2. 工厂普通态与可领取态：五种资源在两秒内可分类；
3. 战区高风险态：危险、战力与出击操作不只靠颜色；
4. 军团编队态：角色身份、空槽和成长入口层级清楚；
5. 普通战斗与 Boss 峰值：新增道具不遮挡单位、弹道、道路或 HUD；
6. 568×320、844×390、1280×540：图标不糊、不裁切、不挤压数字；
7. Web 导出：无缺失依赖、大小写问题或导入错误，记录新增 `.pck` 体积。

## 8. 执行顺序

1. 建立 manifest 与许可证目录；
2. 筛选并引入一套 P0 图标，先做 5 个资源图标和 4 个导航图标的代表性接入；
3. 真实截图检查后再扩展到战斗状态和操作图标；
4. 评估一套 P1 环境包，只接入少量道具到包装场景；
5. 对现有角色做来源审计、材质/动画清单和性能基线；
6. 通过桌面 headless、Web 导出与三档分辨率截图后，才进入 P2。

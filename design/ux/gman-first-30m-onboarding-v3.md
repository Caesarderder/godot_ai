# UX / Gameplay Contract：Gman 首局 30 分钟新手阶段 v3

> 状态：用户已确认方向，待技术设计与实现
> 日期：2026-07-26
> 替代范围：`progressive-onboarding.md` 中与新档四人、图纸退出、单位生产退出、六格初始开放相关的 v2 规则

## 1. 首局承诺

玩家先以孤身出征的 Gman 建立“我很强”的信心，再在 1-4 第一次明确撞墙。失败不是惩罚，而是让玩家亲手得出结论：

> 只靠英雄无法继续扩张；我要让工厂解锁兵种、生产军队，并通过编队形成新的战斗力。

首局证明时刻是：玩家把第一名马桶小兵放入刚解锁的三前排阵位，战力与战场人数立刻变化，并带队重新挑战 1-4。

## 2. 新档初始状态

### 已拥有

- 角色：仅 Gman，永久拥有、默认可出战；
- 战区：仅 1-1 可进攻；
- 工厂：只展示指挥中心，以及处于封锁/待修复状态的建筑地块；
- 编队：系统尚未作为独立功能开放，Gman 自动占据英雄位；
- 资源：只发放完成当前强制路径所需的最低保障资源。

### 未开放

- 科技树；
- 兵种图纸；
- 马桶兵生产建筑；
- 生产队列；
- 编队编辑；
- 后排与扩展阵位；
- 其他永久英雄、招募、派驻、维修深度玩法。

锁定内容可以看见名称或轮廓，但不能同时铺满红点。玩家点击时只显示一个明确条件，例如“通关 1-3 后修复研究所”，不显示资源价格，不允许通过提前囤资源越过阶段门禁。

## 3. 解锁原则

建筑与系统使用双重门禁：

`进度条件满足 → 完成一次引导动作 → 功能解锁 → 才显示资源成本`

- 资源只能支付已经获得使用资格的内容，不能替代剧情或教学进度；
- 每次只开放当前闭环必需的一个主功能；
- 新功能开放后，必须在 30–90 秒内安排一次真实使用；
- 若玩家已有足够资源，仍需完成解锁动作，但不额外制造等待；
- 关键路径奖励必须保证玩家不因误花资源而卡死。

## 4. 30 分钟节奏

时间均为 `playtest hypothesis`，用于首轮实现和真人录像校准。

| 时间 | 阶段 | 玩家行为 | 新知识 | 结束状态 |
|---|---|---|---|---|
| 0:00–2:00 | Gman 登场 | 进入 1-1，观察自动推进并释放一次技能 | 英雄会自动战斗，技能是玩家介入点 | Gman 单人胜 1-1 |
| 2:00–5:00 | 连胜建立信心 | 连续挑战 1-2、1-3 | 敌人逐步增加，Gman 仍能解决 | 1-3 胜利，工厂求援事件触发 |
| 5:00–7:00 | 第一次撞墙 | 挑战 1-4 | 重炮墙是人数/承伤压力，不是操作失误 | Gman 必败，损失受控且不要求维修 |
| 7:00–10:00 | 认识工厂 | 返回基地，依次查看指挥中心、研究所废墟、兵工厂地块 | 工厂功能按战争需求修复，不是资源商店 | 科技树入口开放 |
| 10:00–13:00 | 解锁图纸 | 在科技树点亮“基础马桶兵”根节点 | 图纸决定工厂能生产什么 | 获得基础马桶兵图纸 |
| 13:00–16:00 | 修复生产建筑 | 使用任务保障资源修复“马桶兵工厂” | 建筑资格来自进度，资源用于执行建造 | 生产队列开放 |
| 16:00–19:00 | 第一次生产 | 下达 1 名基础马桶兵订单并完成领取 | 图纸 → 建筑 → 单位是完整生产链 | 第一名小兵进入兵营 |
| 19:00–22:00 | 第一次编队 | 编队功能开放，将小兵放入三前排之一 | 站位决定谁先承伤；空位合法 | Gman + 1 小兵阵容生效 |
| 22:00–26:00 | 形成小队 | 领取加速生产的另外 2 名教学小兵并填满三前排 | 三前排是首个清晰阵型目标 | 三名前排 + Gman |
| 26:00–30:00 | 反攻验证 | 重试并攻克 1-4 | 工厂生产真正改变战斗结果 | 后排第一格或六格扩展目标预告 |

### 节奏护栏

- 1-1 至 1-3 单关目标 35–55 秒，首次结算不弹出复杂养成页；
- 1-4 首次战斗必须正常结算为战败，不能通过数值波动侥幸取胜；
- 首败总伤损不超过 Gman 安全出战阈值，避免在学习生产前插入维修税；
- 首张图纸免费且确定性获得，不抽取、不消耗稀有货币；
- 第一名小兵生产目标 20–40 秒；后两名由新手加速或任务成品补足，首局不等待真实长计时；
- 首次 1-4 失败到“第一名小兵入队”不超过 8 分钟；
- 反攻 1-4 的胜负关键应是新增前排吸收压力，而不是隐藏战力加成。

## 5. 七个新手行动

任务卡只显示当前行动，不展示完整清单；完成后自动衔接，不要求每一步都手动领奖。

### 行动一：孤身先锋

- 目标：使用 Gman 攻克 1-1；
- 必须反馈：Gman 身份、自动推进、技能头像；
- 解锁：1-2；
- 不开放：工厂管理、养成、编队。

### 行动二：继续推进

- 目标：依次攻克 1-2、1-3；
- 1-2 教远程守军，1-3 教轻炮塔；
- 1-3 结算展示“下一城重炮需要更多前排单位”的弱提示，但不提前给答案；
- 解锁：1-4 与工厂求援事件。

### 行动三：高墙

- 目标：完成首次 1-4 挑战；
- 首次挑战锁定为 Gman 单人，允许玩家主动释放技能，但结果必须失败；
- 结算原因固定为“前排兵力不足，Gman 被重炮集中压制”；
- 唯一主 CTA：`返回工厂，寻找增援方案`；
- 此次失败不扣关键资源，不使 Gman 失能。

### 行动四：第一张图纸

- 工厂镜头先落在指挥中心，再引导研究所；
- 研究所因 1-3 战果恢复基础功能，不要求玩家先付资源建造；
- 科技树只亮一个可操作节点：`基础马桶兵图纸`；
- 点击节点后展示三项信息：单位职责“前排承伤”、生产建筑“马桶兵工厂”、对 1-4 的作用；
- 解锁图纸与兵工厂地块。

### 行动五：启动生产

- 玩家用任务保障资源修复马桶兵工厂；
- 建筑落成后自动打开生产页，只有基础马桶兵可选；
- 玩家亲手下达第一单并领取，系统不得直接把单位塞入队伍；
- 资源不足时，行动卡直接补发“战备物资”，不要求重刷旧关。

### 行动六：组建前排

- 第一名小兵领取后才开放“编队”；
- 首次编队只显示三个前排格，Gman 使用独立英雄位，不占三个小兵格；
- 玩家把小兵拖入或点选放入任一前排格；
- 完成后教学加速另外两单，鼓励填满三前排，但不强制指定左右顺序；
- 空格允许保存，重复单位允许占据多个兵位，单位实例必须有稳定 ID。

### 行动七：带队反攻

- 三名前排就位后，主 CTA 直达 1-4 战前页；
- 战前明确对比首次失败与当前阵容：前排人数、预计承伤、总战力；
- 胜利后开放常规工厂循环，并预告下一阵位；
- 若反攻失败，保留小兵，补发一次无损整备和生产材料，允许调整后重试，不能回滚图纸、建筑或编队解锁。

## 6. 编队渐进开放

### 首次开放

```text
        [ Gman 英雄位 ]

[ 前排 1 ] [ 前排 2 ] [ 前排 3 ]

[  锁定  ] [  锁定  ] [  锁定  ]
```

- 三个前排格在第一名小兵生产完成后同时开放；
- 后排三个格保持可见但锁定，避免玩家误以为游戏只有三格；
- 锁定格只显示下一解锁条件，不显示付费入口。

### 六格开放建议

| 阵位阶段 | 条件 | 玩家获得的新选择 |
|---|---|---|
| 三前排 | 第一名基础马桶兵生产完成 | 承伤分配与前排数量 |
| 后排 1 | 首次攻克 1-4 | 可保护第一个远程/辅助单位 |
| 后排 2 | 解锁第二类兵种图纸 | 前后排职责组合 |
| 后排 3 | 攻克 1-5 或指挥中心 Lv.2 | 完整六格编队 |

这是首轮假设。若 1-5 前的教学负担过高，可把后排 2、3 一并放到 1-5 结算后，但不能使用纯资源购买直接解锁阵位。

## 7. 工厂建筑渐进开放

| 建筑/功能 | 初始表现 | 解锁事件 | 首次用途 |
|---|---|---|---|
| 指挥中心 | 已建成 | 新档即有 | 解释工厂总览与锁定条件 |
| 研究所/科技树 | 废墟、不可操作 | 首次 1-4 失败 | 解锁基础马桶兵图纸 |
| 马桶兵工厂 | 锁定地块 | 获得基础图纸 | 生产基础马桶兵 |
| 陶瓷厂 | 锁定地块 | 1-4 反攻胜利 | 支撑持续生产 |
| 零件车间 | 锁定地块 | 第二类兵种需要零件时 | 形成第二条生产门槛 |
| 能源站 | 锁定地块 | 出现持续生产/维修消耗时 | 支撑队列和维修 |
| 维修中心 | 锁定地块 | 首次真实战损需要处理时 | 教快速与等待维修 |

建筑解锁事件和资源建造成本是两个不同状态。未满足事件时，即使资源足够也不能建；事件满足后，玩家才看到建造成本和收益。

## 8. 状态转换与防卡死

```text
Gman 单人推进
  → 1-4 首败已结算
  → 科技树已开放
  → 基础图纸已解锁
  → 兵工厂已建成
  → 第一单位已领取
  → 三前排编队已开放
  → 1-4 已反攻获胜
  → 常规工厂循环
```

- 每个状态单调前进并保存，刷新或退出不能倒退；
- 未来步骤的旧事件不得跳过当前教学；
- 重复点击、重复结算和重复领取不得重复发放图纸、建筑或单位；
- 若存档已越过某一步但缺少关键资产，加载时补齐最低资产并从最近合法步骤继续；
- 教学单位不可在 1-4 反攻前被分解、消耗或永久删除；
- 生产中途退出后按服务器/可信时间继续，若无法可信计时则保持剩余时长，不直接丢单；
- 玩家误花保障资源时，关键订单显示一次性任务补给，不制造软锁。

## 9. 关键反馈

| 事件 | 必须让玩家知道 |
|---|---|
| 1-3 胜利 | Gman 很强，但下一关出现新的规模威胁 |
| 1-4 首败 | 失败原因是前排人数不足；不是技能按错、战力数字不够或需要付费 |
| 研究所恢复 | 战果使工厂出现新能力 |
| 图纸点亮 | 现在“学会生产什么”，尚未直接获得单位 |
| 兵工厂落成 | 建筑把图纸变成可生产订单 |
| 第一名小兵出厂 | 新单位进入兵营，编队入口同时亮起 |
| 小兵入队 | 阵位、战力、预计承伤即时变化 |
| 1-4 反攻胜利 | 首败与胜利镜头形成对照，强调“我带来了一支队伍” |

详细版式、镜头、特效和音频不在本合同内，由视觉与音频设计接续。

## 10. 验收证据

### 确定性检查

- 新档只有 Gman，且只能进入 1-1；
- Gman 单人稳定通过 1-1、1-2、1-3；
- 首次 1-4 无论操作与随机种子都不能胜利，失败原因一致；
- 首败后按顺序开放科技树、基础图纸、兵工厂、生产、编队；
- 资源提前达到建造价也不能提前建造锁定建筑；
- 第一张图纸和首批三名小兵无需抽取或付费；
- 编队首次只开放三前排，Gman 不占兵位；
- 三名前排加入后，目标阵容能稳定通过 1-4；
- 关键命令 exact-once，刷新和存档往返不丢失解锁；
- 反攻再次失败时存在无损恢复路径。

### 真人观察

- 玩家在首败后能说出“我需要增援/前排”，而不是“我要刷战力”；
- 玩家能复述“图纸决定兵种，建筑负责生产，编队决定上场”；
- 玩家第一次出厂时主动寻找编队入口，不需要连续箭头指路；
- 玩家看见锁定建筑时理解为未来目标，而不是资源不足；
- 玩家反攻 1-4 时能感受到战场规模与承伤分配明显变化；
- 30 分钟结束时，玩家知道下一目标是新兵种或新阵位。

## 11. 当前不在本阶段

- 抽图纸、随机图纸品质或付费加速；
- 首局自由摆放建筑、道路和物流；
- 首局英雄招募、升星、派驻、装备与复杂维修；
- 通过单纯囤资源提前解锁建筑或六格；
- 强制填满每个阵位才能出战；
- 首次 1-4 失败造成长时间等待或永久损失。

## 12. 实施边界

本文件只确认玩家规则和验收，不确认运行时架构。现有实现仍以“四名永久角色、六格编队、工厂后勤”为主，和本设计存在 intentional change。下一步应先做技术设计，明确：

- 新档与旧存档迁移；
- 英雄位、可生产兵实例和六格阵位的数据所有权；
- 建筑 `locked / eligible / built` 三态；
- 图纸解锁与生产订单的 exact-once 事件；
- 首次 1-4 必败与后续正常关卡的区分；
- Web 计时、刷新恢复及 844×390 编队可读性。

# UX / Visual Spec：马桶人工厂 SLG 界面刷新

> 状态：已实现第二轮玩家化重构，等待真人触屏复核
> 平台：Godot 4.6.3 / Web / 手机横屏 844×390
> 输入：触屏优先，兼容鼠标与键盘焦点

## 第二轮方向：从交付仪表盘回到游戏世界

第一轮解决了可读性，但仍把大量系统说明、推荐战力、资源效率和操作步骤常驻在首屏，
更像供开发者验收的控制台。第二轮改为：

- UI 使用战报、无线电、侦察影像、出击名单和地下工厂等世界内语汇；
- 每屏只保留一个主行动，系统解释进入档案、详情或设置；
- 标题页先建立 Gman 与失守地表的剧情，不展示完整账号仪表盘；
- 基地用“前线来电”承载当前行动，建造步骤与库存移到下方滚动区；
- 战区首层让路线与五个当前城镇节点保持可见，并用右下情境卡同屏显示推荐战力、能力比、
  风险与唯一主行动；不再设置独立战前会议或二次确认页；
- 军团首层只显示阵型和成员，招募概率、角色成长明细继续留在下层；
- 顶栏移除常驻指挥等级，设置收敛为单个菜单入口；
- 导航使用“工厂 / 战区 / 军团 / 行动”，奖励数量表达为待确认战报，不使用红点劳动语气。

视觉命题调整为：

> 被战火唤醒的地下工厂：焦黑金属承载面、暖橙警戒光、冷青机械回应，
> 平时克制，只有出击、危险和重大收获提升亮度。

## 玩家目标

玩家进入任一界面后，应在两秒内回答两个问题：

1. 当前战争局势发生了什么；
2. 我现在最自然的行动是什么。

成本、收益和详细限制只在玩家准备提交不可逆动作时出现，不提前占据首屏。

## 视觉命题

低模战争玩具工厂 + 深色机械控制台 + 克制的战术荧光。

- 深蓝黑：稳定信息与承载面；
- 青色：当前选择和可立即执行的主行动；
- 金色：资源、收益和成长机会；
- 红色：高战损、失能和不可忽略的风险；
- 绿色：完成、占领和安全战备。

颜色不能单独承担状态。选择同时使用描边与位置，风险同时使用文字，禁用同时降低明度并锁定输入。

## 屏幕信息层级

| 界面 | T0 当前行动 | T1 必须一瞥可读 | T2 按需信息 |
|---|---|---|---|
| 工厂 | 点击 3D 建筑 | 当前行动、可领取、选中建筑 | 完整库存、升级说明 |
| 战区 | 选择城镇节点 | 推荐战力、预计战损、进攻 CTA | 完整敌情与战术建议 |
| 军团 | 选择培养/维修动作 | 角色等级、星级、战备 | 技能说明和工厂专长 |
| 目标 | 继续当前行动 | 行动目标、章节进度 | 永久里程碑列表 |
| 战前 | 确认攻城 | 风险、可出战人数、主 CTA | 敌情长文 |
| 结算 | 继续或维修 | 胜负、净收益、持续伤损 | 详细伤损记录 |

## 核心布局

### 工厂

```text
标题 / 当前语境
┌──────────── 3D 工厂岛 ────────────┬─ 当前行动 ─┐
│ 建筑轮廓、名称、等级、可领取标记 │─ 建筑详情 ─│
│ 点击建筑；当前地块青色高亮       │─ 后勤库存 ─│
└───────────────────────────────────┴────────────┘
                     四入口底部导航
```

当前行动优先于完整库存。资源建筑的领取结果必须报告实际入库量与溢出量；升级前必须展示金币、
工业技术和可感知收益。

### 战区

五张长文卡改为：

1. 章节选择；
2. 五个直接落在战术路线上的可点击城镇节点，不再使用独立按钮条；
3. 单个选中城镇详情；工厂“前线”动作直接聚焦最高已解锁城镇；
4. 稳定位置的风险标记和进攻按钮。

一次只阅读一份敌情，不在五个节点中重复长文。章节超过五个城镇时，节点条围绕当前选择滑动，
不把整章关卡压成一排按钮；章节/城镇选择使用青色，金色只承担当前主行动和底部所在入口。

## 反馈合同

| 事件 | 主反馈 | 辅助反馈 | 时长 |
|---|---|---|---|
| 收取建筑 | 库存数字和资源条更新 | “实际入库 / 溢出”短提示 | 约 2 秒 |
| 选择建筑/城镇 | 描边与详情内容同步 | 按钮 focus 状态 | 即时 |
| 建筑升级 | 世界等级与轮廓刷新 | 显示新等级和收益 | 约 2 秒 |
| 维修 | 战备数字更新 | 恢复后的百分比提示 | 约 2 秒 |
| 战斗结算 | 胜负状态胶囊 | 收益与伤损分栏 | 直到离开 |

## 可用性与响应式

- 所有按钮至少保持稳定最小高度，并支持键盘焦点；
- 世界中文不使用小尺寸 `Label3D`，采用投影后的屏幕空间标签；
- 844×390 不使用横向滚动；
- 长列表只允许纵向滚动，底部导航保持稳定；
- 主状态同时使用文字、颜色和描边；
- 中文长文允许换行，资源数字和比率禁止逐字折行；
- 后续真机验收必须覆盖手指遮挡、浏览器安全区和 40% 文本扩展。

## 验收

- 玩家在战区两秒内能指出当前选中城镇、推荐战力、风险和进攻按钮；
- 工厂首屏能找到当前行动，并能直接点击任一资源建筑；
- 领取一栋建筑后明确看到实际入库，其他建筑生产不被重置；
- 军团首屏至少能浏览三名角色的核心状态；
- 胜利、撤退、失败不只依赖颜色区分；
- 844×390 下资源数字不竖排、主按钮不被裁切、导航始终可见；
- UI smoke、经济循环、存档迁移和真实截图检查通过。
- `run_war_zone_screen_tests.gd` 在 844×342 与 568×272 内容区验证五节点窗口、情境卡边界和
  48 px 主行动；`ui-frontline-briefing-844x390.png` 与 `ui-frontline-briefing-568x320.png`
  是工厂直达前线的标准/短屏代表性截图。

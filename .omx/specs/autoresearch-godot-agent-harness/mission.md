# Mission: Godot Agent-First Game Harness

## Goal

Design an evidence-backed harness for building a bounded Godot game through agent-driven vibecoding.

## Questions

1. Which Godot project structures and engine concepts make agent edits reliable?
2. Which game scope is expressive enough to be worthwhile but deterministic enough to validate?
3. What tools, contracts, observations, tests, and visual checks close the agent feedback loop?
4. How should planning, generation, evaluation, recovery, and project memory interact?
5. What should be adopted from the historical `project-a/` baseline versus designed fresh?

## Acceptance criteria

- Distinguishes repository facts, official Godot guidance, and recommendations.
- Defines a concrete game concept suitable for vibecoding.
- Specifies harness layers, tool contracts, machine-readable state, verification gates, and recovery behavior.
- Includes a phased implementation roadmap and explicit anti-patterns.
- Receives an independent architecture review with verdict `approved`.

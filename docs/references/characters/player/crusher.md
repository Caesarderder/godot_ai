# 液压粉碎马桶人
`implemented`：A级 fighter / 快攻破城 / `heavy.crusher`；
首章阵营十连可作为A级核心候选并同时获得30碎片；4-11首通为后期确定性补领。Lv1–5=`150/36/28/92000/900 → 158/43/30/96830/946 → 166/50/32/101660/992 → 175/57/34/106490/1038 → 183/64/36/111320/1084`；Lv1 CP=`1724/2139/2574`，Lv5目标CP待快照补证（unknown）。
1★6倍结构重击，2★震击守军，3★击破返50能；100能量、100/120/140%。总成本320XP+660币+12数据+90碎片。
一小时教学2-1→2-2→2-4→2-5，回退火箭/双锯。前置巨钳和液压蓄力声负责反馈；若满血结构也成为最优解或一次命中超过结构60%生命，倍率回滚至4倍。

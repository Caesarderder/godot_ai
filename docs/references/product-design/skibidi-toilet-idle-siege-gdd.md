# 《Skibidi Toilet：马桶人工厂攻城》游戏 GDD

## 文档状态

本文定义 `project-a/` 的当前产品方向。2026-07-27 首局合同已经统一为：
仅 Gman 开局，先主动建设研究所；1-2、1-3 首通分别获得冲锋与装甲图纸，研究所逐张研发为两名永久援军，
完成三人反攻后自主选择一条升星路线攻克 1-5 Boss。免费十连只在信号招募功能正式解锁后开放。
工厂只生产后勤资源，不生产或消耗库存单位；完整实现范围与剩余外部门禁以 implementation-status 为准。

## 一句话定位

手机横屏 Web-first 3D 轻量 SLG：玩家经营马桶人工厂，持续生产后勤资源，永久培养马桶人军团，
攻占联盟城镇获得金币、经验与工业技术；金币、角色数据和技能芯片服务角色成长，工业材料与工业技术服务设施建造升级。战斗内伤害决定本局胜负，结算后
永久角色完全恢复，失败后的选择聚焦成长、编队与再战。

## 玩家承诺

玩家从孤身出征的 Gman 开始，把战争中暴露出的职责缺口转化为研究设施、永久援军、编队调整和
自主成长，逐步经营出一支真正的马桶人军团。所有角色都是永久资产；角色培养与工业扩建使用不同
资源账本，主动攻城则提供角色成长战果、工业技术与下一阶段资格。

### 证明时刻

玩家先建成研究所。Gman 单人推进时在 1-2、1-3 分别夺取冲锋与装甲图纸，并在研究所逐张研发两名永久援军；
随后三人突破 1-4 高墙，玩家
自行选择强化冲锋或装甲，再用这次选择压制 1-5 核心巨炮。

## 设计支柱

1. **角色永久、战后无损**：战斗内 HP、阵亡与撤退决定本局结果，结算后永久角色恢复为 100% 可出征。
2. **工厂把战果变成永久成长**：研究所解锁永久援军和能力节点，资源设施持续支撑角色培养与扩建。
3. **主线开疆、战果扩产**：主动攻占城镇产出金币、经验、工业技术与突破资源，解锁下一城镇和更高工厂上限。
4. **低操作、有战前战后选择**：战斗自动移动、索敌和普通攻击；玩家管理角色、阵位、成长路线与技能时机。
5. **短局连续攻城**：单关约 45–75 秒，结算直接连接升级、调整编队和下一关，避免菜单往返。
6. **失败无损但有信息价值**：失败不给完整通关收益，也不损害永久资产；战报必须说明成长墙与下一行动。

## 核心循环

| 步骤 | 玩家行为 | 系统响应 | 关键反馈 |
|---|---|---|---|
| 1. 取得战果 | 推进主线、击败城镇或完成行动 | 解锁建筑资格、研究节点与突破资源 | 新设施、当前职责缺口和下一目标 |
| 2. 建造与研究 | 建造资源设施或研究所、领取产出、完成永久成长 | 原子扣除资源并更新永久角色/设施 | 成本、`ΔCP`、职责收益与落成反馈 |
| 3. 战前整备 | 选择永久角色、站位和技能自动化 | 展示敌方威胁、推荐战力、能力比与首通奖励 | 人数、阵位和克制可读 |
| 4. 自动攻城 | 开战、择机放技能或撤退 | 军团经历外围、守军、核心三段攻坚 | 城市推进、危险预警、基地破坏 |
| 5. 战果结算 | 查看胜负、收益和本局复盘 | exact-once 写入金币、经验与进度，不写永久伤损 | 净成长、失败原因、无损规则 |
| 6. 战后决策 | 升级、调整编队、扩建或继续 | 保留完整永久战力并给出下一行动 | 成长差距和可执行 CTA |
| 7. 扩建再战 | 用战果与资源建造已取得资格的设施 | 提高产能、开放研究或强化永久角色 | 基地外观、军团实力与功能同步成长 |

## 永久角色成长

### 角色数据

每名角色至少包含：

- 稳定 `hero_id` 与型号；
- 等级、当前经验和等级上限；
- 星级与已解锁星级节点；
- 旧存档战备字段只作迁移输入，当前运行时归一为 100；
- 主动技能、被动技能、自动技能偏好；
- 一个工厂专长。

### 等级

等级提供高频、可预测的数值成长，主要消耗金币和基础工业资源：

- 生命与防御；
- 攻击和技能基础值；
- 随行兵力上限；
- 指挥容量或治疗效率。

角色经验主要来自真实出战。经验道具只作为补充，不能完全替代使用角色。

### 星级

星级使用角色碎片、核心数据或章节突破材料，负责机制成长而非单纯倍率：

| 星级 | 首轮节点合同 |
|---|---|
| 1 星 | 基础主动技能与工厂专长 |
| 2 星 | 第一个战斗被动 |
| 3 星 | 主动技能质变或第二个战术效果 |
| 4 星以上 | 长期内容，首个切片不实现 |

工厂专长通过设施派驻生效，例如提高对应产能、增加仓库容量或解锁加工配方。
派驻不得阻止玩家使用喜欢的角色参与主线；同一角色只能强化一个设施。

## 战斗内伤害与无损结算

- 实时 HP、阵亡表现和主动撤退只影响当前战斗结果与复盘；
- 胜利、失败、撤退和重复结算都不得降低永久角色状态或创建维修订单；
- 结算页展示真实本局伤害、击破、失败原因与下一成长建议，但不把伤损转化为跨局税；
- 旧存档中的 readiness、injury 和 repair order 只用于迁移归一化，不进入当前战力或资源预算。

## 工厂设施

首个切片采用可点击的 3D 工厂和 5×5 有界设施选址，不做道路、工人、人口或复杂物流。新档只预建
指挥中心，其余设施先由主线事件获得建造资格，再由玩家选空格、二次确认并支付资源落成 Lv.1；
资源不能越过进度门禁。
旧存档迁移规则由技术设计确定。建筑不是列表入口：
玩家从斜俯视工厂岛直接识别空地、建造、选择并管理建筑；选中地块必须高亮，建造状态和建筑等级
必须在世界空间可见。
资源建筑各自累计产出，建筑上方显示可领取数量，点击建筑即可只收取该建筑的资源，不重置其他
资源建筑的生产时间。功能建筑点击后打开对应管理卡。

| 设施 | 主要产出或职责 | 关键升级行为 |
|---|---|---|
| 指挥中心 | 全局等级上限与功能门禁 | 解锁设施等级、角色等级和新城区 |
| 陶瓷厂 | 自动生产陶瓷 | 提高产速、容量和离线储存 |
| 零件车间 | 加工机械零件 | 解锁高级角色、技能与设施强化配方 |
| 能源站 | 自动生产污水能源 | 提高研究和永久成长可持续时间 |
| 整备中心 | 战斗复盘、编队支援与恢复路径说明 | 提高战前情报和后勤效率，不制造跨局伤损税 |
| 研究所 | 技能、星级和工业科技 | 解锁技能节点与设施质变 |
| 仓库（P0.5） | 资源容量和溢出保护 | 延长安全离线时间 |

设施升级同时包含数值成长和功能节点。关键等级必须解锁新的选择，例如额外派驻位、批量加工、
自动收取或新的研究节点；不能所有等级都只是 `+5%`。

## 经济结构

### 工业资源

- **陶瓷**：角色升级、升星和设施建设；
- **机械零件**：装甲、技能和设施加工；
- **污水能源**：研究、技能与特殊角色成长。

主要由工厂设施持续生产或加工。它们是玩家的时间产能，不是体力；资源不足不能禁止玩家查看或
尝试关卡，但会限制修复和成长效率。

### 战争资源

- **金币**：角色等级、设施升级与常规研究；
- **角色经验**：出战角色成长；
- **工业技术**：设施功能解锁与等级上限；
- **技能芯片/联盟残骸**：技能与高级研究。

主要由城镇胜利、精英目标和任务获得。

### 突破资源

角色碎片、Boss 核心、章节许可证等主要来自首通、Boss 和里程碑，用于升星、解锁角色或重大设施。
它们不能由最低级挂机产能无限制造。

### 经济不变量

- 同一种资源不能在同一闭环中稳定“投入少、产出更多”；
- 工厂资源主要支持永久成长与扩建，战争资源主要支持突破；
- 不设置主线体力、扫荡券或每日挑战次数；
- 通关必需职责由主线确定性提供，不进入随机招募门禁；
- 旧马桶钻、付费图纸抽取和真实支付退出当前范围；下一阶段可使用游戏内招募券招募永久英雄。

### 长期进度层

- 行动任务引导玩家执行已解锁的自然行为，不锁主线；
- 指挥官等级承担账户进度与渐进解锁，不直接增加战斗乘区；
- 28 天战役战令首期只有 30 级免费轨；
- 永久成就记录战役、工厂、军团、成长和收藏里程碑；
- 信号招募只产永久英雄或英雄数据，Gman 和通关必需职责由主线确定性提供；
- 五套系统共享原始玩法事件和 exact-once 奖励账本，领奖事件不得互相产出价值。

详细事件、解锁、概率和奖励预算见
[KM:reference.meta-progression-system](meta-progression-system.md)。
首章完成后的抽取、专属碎片、星级质变、阵营形成和 30–60 分钟旅程见
[KM:reference.post-30m-faction-progression](post-30m-faction-progression.md)。

## 城镇与战斗

### 城镇状态

- **未侦察**：只展示轮廓与章节目标；
- **可进攻**：展示敌情、推荐战力、能力比、主要机制和奖励；
- **已占领**：开放下一城镇、设施上限或少量被动税收，可重玩但不自动推图。

### 阵容

- 最多六名永久角色，保持前后 `2×3` 布阵；
- 空槽允许出战，但不会生成隐藏单位；
- 每名角色拥有清晰职责与可读克制；
- 战区关卡详情不得展示已取消的跨局伤损或维修门禁。

### 三段式攻城

1. 城市外围：快速建立推进与规模感；
2. 联盟防线：引入关卡机制和明显伤损压力；
3. 基地核心：巨炮或结构机制制造高潮和撤退抉择。

战斗仍采用低频确定性领域 tick；3D 破坏、弹道、镜头震动和音效只投影领域事件，不反向决定结果。

### 结果

- 胜利：金币、经验、工业技术/战利品和进度；
- 失败：无完整通关奖励，保留少量实战经验与更准确情报，永久角色完全无损；
- 撤退：无完整通关奖励，保留当前情报，永久角色完全无损；
- 所有结果必须 exact-once，重复结算不得重复发奖或加经验。

## UI 与 UX 合同

### 顶层导航

首期只保留四个稳定入口：

1. **工厂**：资源、设施、派驻和研究；
2. **军团**：角色、等级、星级、技能和阵容；
3. **战区**：章节地图、城镇情报和出征；
4. **目标**：行动任务、免费战令、永久成就和长期反馈。

### 工厂首页

玩家一眼必须看见：

- 六栋具有不同轮廓、名称、等级和点击区域的 3D 建筑；
- 当前三资源数量、每分钟产量和存满时间；
- 当前研究、建造或可领取状态；
- 当前最主要瓶颈；
- 一个主 CTA 和最多两个次级建议；
- 可领取、可升级、资源不足和容量将满的状态差异。

首期建筑交互为“点击建筑 → 立即执行最常用动作或打开专属管理卡”：陶瓷厂、零件车间和能源站
点击即收取对应资源；指挥中心展示全局升级，整备中心展示情报与恢复建议，研究所进入角色与技术研究。

跨屏信息层级、组件状态和 844×390 验收以
[SLG UI 视觉刷新规格](../../../design/ux/slg-ui-visual-refresh.md) 为准。

### 战区关卡详情

章节/城镇地图与选中关卡详情同屏展示。详情必须显示推荐战力、主要威胁、能力比、首通奖励和
“立即出击”按钮；不设置独立战前会议或二次确认页。手机横屏 844×390 下不能依赖横向滚动。

### 战斗 HUD

保留阶段、推进、敌方核心、炮击倒计时、角色状态、技能与撤退。HUD 不展示全部工厂经济，避免遮挡战场。

### 结算页

先展示战争结果，再展示净成长、复盘和下一行动。主 CTA 由状态决定：

- 可安全继续：`进攻下一城镇`；
- 战败：`查看原因与成长建议`；
- 有关键升级：`立即升级`。

结算必须能直接进入成长、编队或下一关，不强迫玩家先返回营地。

## 首个 20–30 分钟切片

### 内容

- 唯一初始英雄：Gman；
- 三个可单人通过的教学城镇、首次必败/可反攻的 1-4 与一个成长检验 Boss 1-5；
- 指挥中心、研究所与三种后勤资源设施；
- 一次信号招募免费基础十连，只给冲锋/装甲图纸与重复设计数据；
- 两次研究所定向研发，分别把图纸转化为唯一永久援军；
- 一个显示全部马桶角色、B/A/S 评级和未发现/有图纸/已研发状态的图鉴；
- 最多六人的 `2×3` 永久角色编队；
- 一次被解释为兵力需求的无惩罚首败；
- 一次由永久援军改变结果的 1-4 反攻；
- 一次由玩家自主选择冲锋或装甲升星路线改变结果的 1-5 决战。

### 玩家旅程

1. Gman 单人攻克 1-1、1-2、1-3，建立英雄强度信心；
2. Gman 在 1-4 被重炮墙稳定击败，并明确看见“缺少前排兵力”的原因；
3. 在信号招募页接收免费基础十连，获得冲锋与装甲设计图纸；
4. 返回工厂，在 5×5 网格主动建造研究所，并逐张研发两名永久援军；
5. 把两名援军加入 `2×3` 编队并攻克 1-4；
6. 比较冲锋二星与装甲二星的职责收益，自主选择一条经济可达路线；
7. 用所选成长处理 1-5 巨炮机制并完成首章。

详细节奏、门禁、防卡死和验收见
[首章 30 分钟关卡、任务与成长体验规划](../constraints/first-30m-contract.md)。

### 试玩必须回答

- 玩家能否复述“战果开放研究、工厂支持成长、永久角色组成军团”？
- 玩家是否理解 Gman、冲锋和装甲都是不会被消耗的永久角色？
- 玩家在 1-4 首败后是否主动想到需要增援，而不是刷等级或付费？
- 玩家是否理解建筑先由进度取得资格，再支付资源建造？
- 玩家能否说出冲锋与装甲的职责差异，并预测所选升星如何帮助 1-5？
- 反攻胜利是否让玩家感到工厂真正改变了战争结果？

## 当前不做

- 量产或消耗库存单位、图纸材料抽取；
- 自动扫荡或自动首次推图；
- 可永久删除的核心角色；
- 超出当前 5×5 有界选址的自由建造、道路和复杂物流；
- 多队大地图、PvP、公会和排行榜；
- 装备随机词条、套装和多层角色养成；
- 马桶钻图纸材料混池、付费抽取、真实充值与广告；
- 主线体力、每日次数和 FOMO 日常。
- 4★/5★完整内容和额外常驻阵营乘区；30–60 分钟切片先验证 1★→2★ 的阵营成形。

## 平衡假设

- 单关目标 45–75 秒；
- 工厂基础容量覆盖 8–12 小时普通离线；
- 失败后的下一次有意义成长必须可通过现有工厂产能或可重复战果达到，不能形成等待死锁；
- 玩家每 2–3 场应获得一次角色或设施的可见提升；
- 首轮数值必须由确定性模拟和真人试玩共同验证，文档中的比例不是最终平衡。
- 战力、资源价值、推进能力、失败恢复压力与内容寿命统一使用
  [KM:reference.game-state-measurement-framework](game-state-measurement-framework.md)，不得各系统私建汇率。

## 发布边界

当前项目使用 Skibidi Toilet 角色、名称和世界观做本地设计与同人原型。商业部署前必须获得覆盖
角色、名称、世界观、素材和商业运营的书面授权，并完成发行、支付、未成年人保护、隐私和素材来源审查。

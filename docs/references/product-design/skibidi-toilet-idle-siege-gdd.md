# 《Skibidi Toilet：马桶人工厂攻城》游戏 GDD

## 文档状态

这是一份当前 `project-a/` v2 方向的产品设计参考。它定义《Skibidi Toilet：马桶人工厂攻城》的长期玩法目标；当前实现状态以 [KM:reference.implementation-status](../constraints/implementation-status.md) 为准，尚未落地的内容不得仅凭本 GDD 宣称已完成。

本文区分三种信息：

- **已确认**：开发者在策划会话中明确接受的产品决策。
- **设计假设**：为形成可玩版本而提出、仍需试玩验证的可逆参数。
- **待决定**：会实质改变内容范围或实现边界，不能静默代替开发者选择。

## 产品定位

### 已确认

- 题材与世界观：直接使用 `Skibidi Toilet` 的角色、阵营和世界观。
- 发布方式：公开免费的非商业同人游戏，不设置广告、内购或付费内容。
- 首发平台：Web 浏览器，主要使用场景是手机浏览器横屏游玩。
- 表现形式：横屏 3D 休闲放置游戏，战斗采用自走棋式自动移动、索敌和攻击。
- 核心结构：工厂放置经营与独立自动攻城关卡分离。
- 核心展示承诺：玩家第一眼和每局高潮都应是军团沿城市大道推进并摧毁联盟基地的 3D 攻城大场面；工厂服务于攻城，不与战斗平分展示权重。
- 主线叙事：使用原作世界观、阵营和标志性角色，讲述一条原创的平行战争线，不逐集复述或严格重演原作事件。
- 阵营结构：主线始终以地球 Skibidi 阵营为玩家方；通关主线后解锁独立的 Astro 征服战役，不在中途用 Astro 替换玩家已经培养的地球军团。

原作阵营、角色形态和命名边界以 [KM:reference.skibidi-toilet-lore-research](skibidi-toilet-lore-research.md) 为准。平行战争线可以重新组合城市、战役和基地 Boss，但必须明确与原作的分歧点，不能把原创事件伪装成原作正史。Astro 入侵后 Skibidi 与 Alliance 临时合作仍是重要背景，因此持续攻打 Alliance 的主线需要在时间线或阵营动机上给出自洽解释。

### 发布边界

公开免费不等于获得 IP 授权。发布版本必须：

- 显示清晰的非官方同人声明，不宣称获得原作者或权利方背书；
- 保留替换、撤下争议名称、模型、音频和角色素材的能力；
- 不把未经确认的第三方模型、音乐、音效或商标写入可发布资产清单；
- 在真正公开部署前单独完成素材来源与发布授权审查。

本 GDD 只确认玩法方向，不构成授权结论。

## 玩家承诺与证明时刻

**玩家承诺：** 玩家经营一座持续运转的马桶人工厂，亲手生产、合成和编成稀有 Skibidi Toilet 角色，再带领军团沿城市大道顶着持续炮火推进，在短促、厚重的 3D 攻城战中摧毁联盟基地。

**可观察的证明时刻：** 玩家在一次失败后回到工厂，将三个相同角色永久合成为高星角色，重新编队，再按自己的自动技能设置或手动技能时机顶住核心巨炮的持续轰炸，在最后一名主力倒下前摧毁联盟基地。

## 设计支柱

1. **稀有角色值得拥有**：角色获取有成本，重复角色既能同时上阵，也能作为升星材料。
2. **低操作但有选择**：移动、索敌、普通攻击和技能选目标自动完成；玩家可以自由选择手动释放技能或开启自动技能，不设置首通门槛。
3. **生产选择可预期**：玩家通过分类车间和指定配方生产目标角色，不使用完全随机抽取作为核心来源。
4. **短局大场面**：每场战斗约一分钟，必须出现清晰的突破、防守升级和最终攻城高潮。
5. **失败推动成长**：失败把玩家送回工厂进行生产、合成和阵容调整，不用重复无意义操作。
6. **剧情失败不抹除投入**：工厂可以在剧情中被摧毁，但永久角色、星级、关键蓝图和长期收藏不能被剧情清空。

## 核心循环

| 步骤 | 玩家意图或输入 | 规则与世界响应 | 关键反馈 | 新状态 |
|---|---|---|---|---|
| 1. 选择配方 | 在分类车间选择要生产的角色 | 检查蓝图、材料和生产槽，满足条件后进入计时队列 | 角色模型预览、材料扣除、倒计时启动 | 生产队列运行 |
| 2. 放置收取 | 在线等待或离线返回 | 完成的配方生成一星角色实例 | 生产线开门、角色登场、稀有度光效 | 角色进入库存 |
| 3. 合成取舍 | 选择三个同角色实例 | 三个实例永久合成一个更高星实例；未合成副本仍可同时上阵 | 三合一动画、体型或装备升级、技能强化提示 | 库存数量减少、单体强度提高 |
| 4. 编成小队 | 选择六个角色并安排战前站位 | 同名角色允许重复；每个位置绑定一个独立角色实例 | 阵容战力、角色职责和技能预览 | 出征阵容锁定 |
| 5. 自动攻城 | 开始关卡 | 六名主力自动移动、索敌、普通攻击；关卡依次进入守军、防御设施、基地或 Boss 三段 | 镜头推进、目标切换、阶段破坏 | 战斗持续推进 |
| 6. 技能策略 | 设置自动技能，或点击已充能角色技能 | 系统自动选择合法且高价值目标；部分技能生成临时召唤物 | 头像充能、施法预警、命中与伤害反馈 | 战场局势改变 |
| 7. 结算成长 | 摧毁最终目标或触发失败 | 胜利发放材料和蓝图进度；失败保留既有角色并返回工厂 | 胜负原因、关键贡献、下一步建议 | 新一轮生产或重试 |

## 长期战役与阵营结构

### 第一幕：地球马桶人的扩张

- 玩家经营 Chief Scientist 体系下的固定地下工厂，生产并培养地球 Skibidi 军团。
- 主要敌人是 Cameramen、Speakermen、TV Men 组成的 Alliance；关卡目标是攻破城市防线、军事设施和联盟基地。
- 玩家通过回收联盟残骸获得蓝图和反制技术，逐步解锁飞行、重装、寄生、维修和攻城单位。
- 第一幕要制造“玩家正在赢得战争”的上升感，为后续联盟反攻形成反差。
- 第一幕采用五章二十五关结构，详细故事、角色池、敌军梯度、Boss 和蓝图解锁见 [KM:reference.earth-skibidi-act1-campaign](earth-skibidi-act1-campaign.md)。
- 第一幕角色的来源状态、职责、技能、克制和制作优先级见 [KM:reference.earth-war-character-roster](earth-war-character-roster.md)。

### 第二幕：联盟反攻与移动工厂

- 玩家攻破一座关键联盟基地后触发不可避免的章节剧情败北；升级后的联盟泰坦和突击部队沿进攻路线反推出玩家工厂位置。
- 旧工厂在剧情演出中被摧毁，固定生产线、设施等级、部分普通材料和区域控制权可以受损或失去。
- 永久角色实例、星级、已解锁关键蓝图、传奇角色、故事关键物和玩家偏好设置必须通过核心数据库与紧急撤离保留，不能用剧情杀清空玩家长期投入。
- 未完成生产订单和普通材料的具体损失比例属于后续数值设计，但必须提前警示并提供残骸回收或重建补偿，不能制造毫无预告的资源归零。
- 玩家随后建立移动战争工厂。重建不是原设施的机械重复升级，而是解锁快速部署、战场回收、模块化生产和迁移到新城市的能力。

### 第三幕：Astro 入侵与地球防卫

- Astro 舰队抵达后同时攻击地球 Skibidi 与 Alliance，并追杀已经脱离 Astro 的 G-Toilet。
- 玩家继续使用自己培养的地球 Skibidi 军团，不因剧情切换而失去原阵容。
- 地球 Skibidi 与 Alliance 进入脆弱的临时合作；关卡目标由摧毁联盟基地转向抵抗 Astro、救援临时盟友、夺取外星设施和保护移动工厂。
- 玩家通过击败 Astro 回收护盾、曲速、反重力和高能武器技术，用于升级既有地球单位或解锁少量被俘、叛逃的特殊 Astro 角色。

### 通关后：Astro 征服战役

- 完成地球 Skibidi 主线后，解锁独立的 Astro 征服战役。
- Astro 使用母舰、军事阶级和外星生产体系，敌人同时包括 Alliance 与地球 Skibidi。
- Astro 战役拥有独立阵营进度和编队，不覆盖、删除或替换地球主线的工厂、角色和收藏。
- 两条战役是否共享少量通用资源或挑战奖励，留待后续经济设计；不得允许第二战役反向破坏第一战役的养成平衡。

### 首个可玩前 30 秒

**设计假设：**

1. 玩家进入正在运转但尚未扩建的工厂，普通车间点亮，其余三个车间以可预览的锁定状态出现；
2. 界面直接赠予第一份普通配方所需材料，并把“选择配方”作为唯一主目标；
3. 玩家选择一个基础 Skibidi Toilet 配方，首个教学订单压缩为约 5 秒；
4. 生产线开门并展示第一个永久角色，库存显示 `1 / 6`，下一目标明确指向“完成第一支出征小队”；
5. 这段教学不自动替玩家选择后续配方，不自动合成，也不制造付费或随机抽取预期。

## 工厂与生产

### 分类车间

| 车间 | 已确认职责 | 典型角色定位 |
|---|---|---|
| 普通车间 | 低成本、较短周期的基础配方 | 基础近战、基础远程、低费前排 |
| 飞行车间 | 生产可越过地面阻挡的角色 | 空中突袭、后排压制 |
| 重装车间 | 生产大型、耐久或攻城角色 | 承伤、破坏设施、推进 |
| 特殊车间 | 生产拥有控制、召唤或特殊机制的角色 | 寄生、控制、辅助、标志性角色 |

### 材料结构

已确认采用三种共享材料与角色专属蓝图：

- 陶瓷组件；
- 机械零件；
- 污水能源；
- 角色专属蓝图。

不同配方通过材料比例、蓝图要求和生产时间体现差异。材料不为每个角色新增独立背包品类。

### 离线生产

当前纵向切片固定 3 个生产槽。已加入队列的配方使用绝对完成时间，离线期间继续计时；返回后可一次领取全部到期订单，每个订单只能领取一次。离线不会自动选择新配方、自动消耗新材料或自动合成角色。因为只有已排入的 3 个订单继续计时，当前不另设离线时长上限；正式扩展队列前重新评估。

### 首个切片八原型与星级技能

| 配方 | 一星职责 / canonical 技能 | 二星质变 | 三星质变 |
|---|---|---|---|
| `ordinary.assault` | 前线突破 / `plunger_charge` | 冲锋后顺劈当前守军层 | 追加眩晕仍存活的守军 |
| `ordinary.sonic` | 声波削弱 / `sonic_disruptor` | 从本战斗带扩大到当前守军全线 | 追加压制普通守军行动 |
| `flying.rocket` | 远程攻城 / `rocket_salvo` | 单目标齐射变为当前层范围齐射 | 对结构施加持续破甲 |
| `flying.bomber` | 自损爆发 / `suicide_dive` | 爆点波及当前层其他目标 | 取消施法后的自损退场风险 |
| `heavy.armored` | 全队护盾 / `siege_shield` | 追加冲门伤害 | 强制当前精英优先攻击施法者 |
| `heavy.saw` | 精英斩杀 / `saw_rush` | 对精英追加一次连斩 | 击杀后返还能量 |
| `special.repair` | 单体急救 / `field_repair` | 扩大为三名低血主力 | 每场可拉起一名倒下的永久主力 |
| `special.parasite` | 召唤幼体 / `parasite_swarm` | 每次召唤数量由一变二 | 优先策反一名普通联盟守军 |

技能 ID 的唯一事实源是 `FactoryCatalog`；职业只参与基础成长和攻击节奏，不再决定主动技能。

## 角色、稀有度与合成

### 固定稀有度

| 稀有度 | 强度与机制定位 | 获取预期 |
|---|---|---|
| 普通 | 基础属性和清晰单一职责 | 配方成本最低、最容易升星 |
| 稀有 | 更高属性并具备明确战术优势 | 需要更多材料或蓝图 |
| 史诗 | 主动技能可明显改变局部战局 | 较长生产周期、蓝图更少见 |
| 传说 | 标志性角色或形态，拥有强力主动技能 | 长周期、高成本、稀有蓝图 |

- 每个角色拥有固定稀有度，不随机生成品质。
- 同一角色的不同进化形态作为独立角色和独立配方，例如不同阶段的 G-Toilet。
- 稀有度决定基础强度、技能上限和生产成本；星级决定同一角色实例的成长程度。

### 永久合成

已确认规则：

```text
3 个同角色、同星级实例 → 1 个下一星级实例
```

- 合成只发生在工厂，不在战斗中临时合成。
- 同名角色允许重复上阵，最多可占满六个编队位置。
- 每个上阵实例独立拥有生命、能量和技能状态。
- 玩家必须在“保留多个低星角色形成数量优势”和“合成更少的高星角色形成质量优势”之间选择。
- 关键星级应强化或改变技能表现，避免升星只做无感的线性数值增长。

## 战斗契约

### 阵容与自动行为

- 每场使用六名永久主力角色。
- 战前选择角色和站位；开战后不手动控制移动和普通攻击。
- 角色根据职责、攻击距离和目标规则自动移动、索敌和攻击。
- 玩家不点击敌方单位、不标记集火目标、不拖动角色，也不手动控制镜头。
- 伤害技能自动选择当前高价值合法目标，治疗和护盾技能自动选择最需要保护的主力，召唤物自动从队伍后方进入战场。
- 主力全部阵亡或计时耗尽时失败；临时召唤物阵亡不计入失败条件。
- 战斗中不生产永久角色，也不进行永久合成。

首个可玩版本采用前后两排、每排三个位置的固定战前站位；角色离开出生位置后由自动战斗逻辑接管。

### 主动技能

- 每个角色至少拥有基础属性、自动攻击、被动或特性，以及一个主动技能。
- 每个角色实例独立积攒技能能量。
- 自动技能默认关闭，由玩家主动开启；从首次进入战斗起即可设置，不以首通或重复刷关为解锁条件。
- 玩家改变自动技能开关后，后续战斗沿用该玩家设置，直到玩家再次主动修改。
- 关闭自动技能时，头像显示能量状态并作为技能按钮；未满足条件时不能释放，点击后无需二次瞄准。
- 自动技能的具体设置入口由 UI 阶段按手机横屏可用性决定，不属于产品方向决策；不得改变“默认关闭、玩家主动开启、跨战斗记忆、无首通限制”的规则。
- 一部分角色技能可以召唤临时马桶杂兵、寄生单位或自爆单位。
- 临时单位只存在于当前战斗，不进入库存、合成或永久养成。

### 三段式攻城

```text
城市外围：联盟守军与路障
→ 火力封锁区：炮塔、精英与装甲大门
→ 基地广场：普通/精英近卫 → 左右电池 → 核心外甲 → 联盟基地核心巨炮
```

- 战场是一条通向联盟基地的宽阔城市大道，远处基地从开战时就可见，并随推进逐渐变大、变近。
- 大道内部可使用左、中、右三个隐形战斗带帮助单位避让和表现阵型，但玩家不操作分路。
- 常态镜头采用斜侧后方低俯视角；阶段突破、巨型目标登场、少量史诗技能和最终坍塌可以短暂自动切镜。
- **成功：** 在时间耗尽前摧毁最终基地或击败 Boss。
- **失败：** 六名主力全部阵亡，或关卡计时耗尽。
- **恢复：** 回到工厂，保留永久角色和已完成成长，重新生产、合成或调整阵容。
- **重试：** 玩家重新确认阵容后从关卡初始状态开始，不继承上次战斗的生命、能量和临时召唤物。

### 第一章 Boss：联盟基地核心巨炮

- 核心巨炮与基地建筑融为一体，由左右防御设施、外层装甲、核心炮管和基地主体构成，不是从基地中走出的独立机甲。
- 巨炮持续轰炸全场，炮击频率和战场压力随阶段提高，迫使双方进行输出与生存竞速。
- 摧毁左右设施会降低后续炮击压力；击穿外层装甲后，核心在散热或过载窗口受到更高伤害。
- 玩家不通过走位或手动选目标规避炮击；阵容中的重装、治疗、护盾、召唤与攻城职责决定承压方式，技能开关与释放时机决定爆发效率。
- 理想结局是双方同时接近崩溃，玩家在残血压力下先一步摧毁核心，而不是满血清空静态血条。

### 3D 美术与破坏方向

- 整体采用风格化写实：混凝土、钢铁、沥青、沙袋、弹痕、焦黑与机械结构具有可信重量，避免照片级资产成本。
- 光照从阴沉白天逐步转为黄昏战火；变化由火焰、黑烟、尘土、警报灯和暖色爆炸推动，不表现一分钟内太阳快速落山。
- 爆炸反馈至少包含命中前轨迹或蓄力、瞬间闪光和冲击波、碎片与火焰、扬尘、持续黑烟、延迟坍塌、镜头震动和低频音效中的必要组合。
- 建筑破坏采用完整、重度受损、摧毁三段预制状态；只让少量关键碎片短时使用物理模拟，不做全实时物理拆楼。
- 玩家军团与联盟防御必须在手机小屏幕上保持阵营、轮廓和目标可读性；远景爆炸主要制造战争规模，不参与战斗计算。

## 关键反馈契约

| 关键事件 | 最低反馈要求 |
|---|---|
| 配方开始 | 材料飞入设备、生产线启动、剩余时间清晰可见 |
| 生产完成 | 车间开门、角色完整亮相、名称与稀有度同时出现 |
| 三合一升星 | 三个实例汇聚、轮廓或装备升级、属性与技能变化可比较 |
| 技能就绪 | 角色头像充能完成、短音效和轻量脉冲，不遮挡战场 |
| 技能释放 | 施法者、目标区域和结果在同一战斗节拍内可辨认 |
| 阶段突破 | 防线被破坏、镜头向前推进、下一目标明确出现 |
| 核心炮轰炸 | 炮弹轨迹、落点、冲击和队伍承压可辨认，近景烟尘不能长期遮住角色与技能头像 |
| 胜利 | 核心炮过载、基地连续爆炸并分段坍塌，奖励来源与下一步成长路径清楚 |
| 失败 | 明确区分全灭和超时，并提示炮击承压、输出效率、阵容、星级或技能设置中的一个可行动方向 |

## 首个可玩内容切片

### 必须证明

1. 一条指定配方生产完整流程；
2. 三个同角色永久合成一次；
3. 六人阵容允许至少两个同名角色同时上阵；
4. 一场包含三段目标的自动攻城；
5. 至少两个角色拥有可主动释放、效果不同的技能；
6. 至少一个技能生成临时召唤物；
7. 一次失败回厂成长后再胜的闭环；
8. 自动技能从首次战斗起可自由设置，关闭后可以仅凭角色头像完成手动施法；
9. 一条从阴沉城市外围推进至黄昏战火基地广场的 3D 城市大道；
10. 核心巨炮持续轰炸、基地模块分段受损和最终连续坍塌；
11. Web 浏览器中鼠标和触屏均可完成核心操作，并在目标手机浏览器上保持可读、可操作。

### 设计假设

- 首个切片准备 8 个可生产角色，让六人阵容存在至少两种替换选择。
- 四类车间各至少展示一个配方，其余配方可以锁定预览。
- 首个切片包含 3 个关卡：教学防线、精英设施、章节 Boss。
- 单局目标时长为 45–60 秒。
- 首个章节 Boss 使用与联盟基地融为一体的核心巨炮，不追加完整巨型机甲的独立动画预算。

### 明确暂不做

- 商业化、广告、内购和付费抽取；
- PvP、排行榜、公会、玩家交易和联机协作；
- 连续开放世界或无缝城市扩张；
- 战斗内购买角色或临时三合一；
- 手动控制角色移动和普通攻击；
- 手动选择敌方目标、点击基地部件集火和自由控制战斗镜头；
- 全实时物理建筑拆毁和依靠超大单位数量制造规模；
- 在首个可玩切片中实现旧工厂剧情摧毁、移动工厂完整重建或 Astro 独立战役；
- 完整复述原作所有章节与角色；
- 未经素材审查的公开部署。

## 数值与调优契约

| 值 | 初始范围或关系 | 预期玩家效果 | 调整证据 |
|---|---|---|---|
| 编队人数 | 已确认 6 名 | 允许角色组合与重复角色取舍，同时保留技能可管理性 | 玩家频繁误触或无法关注多个技能时再缩减 |
| 合成需求 | 已确认 3 合 1 | 让副本保留和升星之间形成真实选择 | 玩家总是无脑合成或永不合成时调整生产成本和星级收益 |
| 关卡结构 | 已确认 3 段 | 每局形成建立、升级和高潮 | 玩家无法辨认阶段变化时加强目标和镜头反馈 |
| 单局时长 | 假设 45–60 秒 | 适合浏览器短会话，并允许至少一次技能决策 | 大多数测试者在中段前离开或技能尚未就绪时调整 |
| 材料种类 | 已确认 3 种共享材料加蓝图 | 保留配方差异，不让背包认知过载 | 测试者无法解释材料用途时合并材料 |
| 稀有度 | 已确认 4 档 | 快速表达强度、成本和期待值 | 低稀有角色完全失去使用率时强化低稀有升星效率 |
| 新档材料 | 瓷片/零件/污泥 = 120/100/80 | 可完成教学生产，并在首败后承担一次重装反攻配方 | 玩家首败后无法生产已解锁反制单位时提高失败返还 |
| 生产槽 | 当前 3 个 | 保留短会话排程选择，避免无限离线堆积 | 三槽长期空置或持续满载时再调整 |
| 训练 | 每本 20 XP、30 金币，L1–L5 | 让失败奖励立刻转成可见战力 | 玩家获得训练书却无法形成等级变化时调整阈值 |
| 失败返还 | 全灭 8/5/4；超时 4/3/2；均给 2 本训练书 | 失败代价低于胜利，但不形成死档 | 玩家无成长动作或故意刷失败时调整 |
| 胜利返还 | 24/16/12、1 本训练书 | 支撑下一次生产选择与蓝图扩张 | 首胜后仍只有唯一生产答案时调整 |

## 验收与试玩证据

| 行为或假设 | 确定性检查 | 真人观察 | 通过信号 |
|---|---|---|---|
| 指定生产 | 材料足够时只有玩家选择的配方进入队列，材料不足时不扣除任何材料 | 新玩家能说出正在生产哪个角色及剩余时间 | 无需说明即可完成首次生产 |
| 永久合成 | 只有三个同角色、同星级实例能够生成一个下一星级实例 | 玩家会在保留三份和升星之间犹豫 | 至少一种关卡使两种选择都可解释 |
| 重复上阵 | 两个以上同角色实例可以同时进入六人阵容并独立战斗 | 玩家理解它们是独立实例而非显示重复 | 能分别观察到生命、能量和技能状态 |
| 自动攻城 | 开战后不输入移动指令也能依次进入三段目标 | 玩家能在十秒内指出当前目标 | 不需读实现说明即可理解推进方向 |
| 技能设置 | 自动技能无首通门槛；关闭自动后，能量未满不可释放，充满后点击只触发对应实例一次且自动选目标 | 偏放置玩家能全自动观看，偏策略玩家会主动切换并掌握技能时机 | 两种设置都能完成战斗，且不会要求点击移动中的 3D 单位 |
| 核心巨炮 | 炮击按阶段持续升级，基地模块受损会改变后续压力，最终核心可被摧毁 | 玩家能说出队伍是输出不足还是承压失败 | 失败原因与回厂后的成长或换阵行动对应 |
| 临时召唤 | 召唤物不进入永久库存，战斗结束后全部清理 | 玩家享受军团规模突然扩大的场面 | 不会误以为召唤物可以带回工厂 |
| 失败恢复 | 全灭或超时后停止战斗写入，回厂后永久成长仍保留 | 玩家失败后主动生产、合成或换阵，而非直接退出 | 至少一名新玩家完成失败后成长再胜 |
| Web 输入 | 鼠标与触屏均可完成生产、合成、编队和施法 | 玩家不需要精确点击移动中的 3D 单位 | 关键操作只依赖稳定 UI 目标 |

## 概念性 Godot 边界

本节只约束所有权和数据流，不决定最终场景树或类名。

| 所有者 | 负责 | 不负责 |
|---|---|---|
| 工厂持久状态 | 材料、蓝图、生产队列、角色实例、星级 | 当前战斗生命、能量和召唤物 |
| 玩家偏好设置 | 自动技能开关等跨战斗偏好，玩家修改后保持到下次主动修改 | 当前战斗技能能量、目标和释放结果 |
| 战役持久状态 | 当前幕、章节进度、旧工厂/移动工厂状态、Astro 战役解锁状态 | 单场战斗生命、能量和临时召唤物 |
| 阵营进度 | 地球 Skibidi 与 Astro 各自的工厂、角色池、编队和阵营成长 | 静默删除或覆盖另一阵营的永久收藏 |
| 编队状态 | 六个出征槽和战前站位 | 自动索敌与即时战斗结果 |
| 关卡定义 | 三段目标、敌人配置、时间限制、奖励表 | 玩家永久库存 |
| 战斗运行状态 | 主力战斗副本、生命、能量、目标、临时召唤物和胜负 | 永久合成与离线生产 |
| 结算边界 | 将已确认的胜负与奖励一次性写回持久状态 | 在战斗过程中直接改写工厂库存 |

关键数据流：

```text
工厂持久状态
→ 生成只读出征快照
→ 战斗运行状态自动推进
→ 玩家手动触发或自动技能策略触发某个角色实例的主动技能
→ 胜负结算
→ 奖励一次性写回工厂持久状态
```

Web 实现必须验证：

- 3D 战斗在目标浏览器和手机浏览器中的帧率、首包体积与内存；
- 页面失焦、切后台、刷新和断线时生产计时与战斗状态的处理；
- 鼠标与触控共享同一套确定性操作语义；
- 临时召唤物和重复角色不会在重试、切场景或刷新后残留。

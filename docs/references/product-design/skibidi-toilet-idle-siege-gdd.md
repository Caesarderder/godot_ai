# 《Skibidi Toilet：马桶人工厂攻城》游戏 GDD

## 文档状态

本文定义 `project-a/` 的产品方向。2026-07-26 新确认的首局 v3 新手阶段为：
仅 Gman 开局，单人攻克前三关，在 1-4 首次撞墙后，通过科技图纸解锁基础马桶兵，
修复生产建筑、生产小兵并开放三前排编队，再组织反攻。现有运行时已实现新档仅 Gman，
后续永久角色通过战役 Boss 与招募进度解锁；完整实现范围与剩余偏差必须以 implementation-status 为准。

## 一句话定位

手机横屏 Web-first 3D 轻量 SLG：玩家经营马桶人工厂，持续生产后勤资源，永久培养马桶人军团，
攻占联盟城镇获得金币、经验与工业技术，再用战果扩建工厂；战斗内伤害决定本局胜负，结算后
永久角色完全恢复，失败后的选择聚焦成长、编队与再战。

## 玩家承诺

玩家从孤身出征的 Gman 开始，把战争中暴露出的需求转化为图纸、建筑和可部署部队，
逐步经营出一支真正的马桶人军团。Gman 与重要英雄是永久资产；工厂生产的基础兵种扩大阵容与承伤能力，
战果继续解锁工厂建筑、兵种科技和阵位。

### 证明时刻

Gman 单人连胜三关，却在 1-4 被联盟重炮集中压制。玩家回到工厂，点亮第一张基础马桶兵图纸，
修复兵工厂并亲手生产三名前排小兵。再次开战时，炮火被前排分担，Gman 带领新军攻破此前的高墙。

## 设计支柱

1. **角色永久、战后无损**：战斗内 HP、阵亡与撤退决定本局结果，结算后永久角色恢复为 100% 可出征。
2. **工厂把科技变成军队**：科技树决定可生产兵种，生产建筑把图纸变成可部署单位；后勤设施再支撑培养和扩建。
3. **主线开疆、战果扩产**：主动攻占城镇产出金币、经验、工业技术与突破资源，解锁下一城镇和更高工厂上限。
4. **低操作、有战前战后选择**：战斗自动移动、索敌和普通攻击；玩家管理英雄、生产兵、阵位与技能。
5. **短局连续攻城**：单关约 45–75 秒，结算直接连接升级、调整编队和下一关，避免菜单往返。
6. **失败无损但有信息价值**：失败不给完整通关收益，也不损害永久资产；战报必须说明成长墙与下一行动。

## 核心循环

| 步骤 | 玩家行为 | 系统响应 | 关键反馈 |
|---|---|---|---|
| 1. 取得战果 | 推进主线、击败城镇或完成行动 | 解锁建筑资格、科技节点与生产资源 | 新地块、新图纸和当前战争需求 |
| 2. 研究与生产 | 解锁兵种图纸、修复对应建筑、下达订单 | 原子扣除资源并生成可部署单位 | 图纸用途、队列时间、出厂反馈 |
| 3. 战前整备 | 选择英雄、生产兵、站位和技能自动化 | 展示敌方威胁、推荐战力、能力比与首通奖励 | 人数、阵位和克制可读 |
| 4. 自动攻城 | 开战、择机放技能或撤退 | 军团经历外围、守军、核心三段攻坚 | 城市推进、危险预警、基地破坏 |
| 5. 战果结算 | 查看胜负、收益和本局复盘 | exact-once 写入金币、经验与进度，不写永久伤损 | 净成长、失败原因、无损规则 |
| 6. 战后决策 | 升级、调整编队、扩建或继续 | 保留完整永久战力并给出下一行动 | 成长差距和可执行 CTA |
| 7. 扩建再战 | 用战果与资源建造已取得资格的设施 | 提高产能、开放兵种或解锁阵位 | 基地外观、军队规模与功能同步成长 |

## 永久角色成长

### 角色数据

每名角色至少包含：

- 稳定 `hero_id` 与型号；
- 等级、当前经验和等级上限；
- 星级与已解锁星级节点；
- 旧存档战备字段只作迁移输入，当前运行时归一为 100；
- 主动技能、被动技能、自动技能偏好；
- 一个工厂专长。

### 等级

等级提供高频、可预测的数值成长，主要消耗金币和基础工业资源：

- 生命与防御；
- 攻击和技能基础值；
- 随行兵力上限；
- 指挥容量或治疗效率。

角色经验主要来自真实出战。经验道具只作为补充，不能完全替代使用角色。

### 星级

星级使用角色碎片、核心数据或章节突破材料，负责机制成长而非单纯倍率：

| 星级 | 首轮节点合同 |
|---|---|
| 1 星 | 基础主动技能与工厂专长 |
| 2 星 | 第一个战斗被动 |
| 3 星 | 主动技能质变或第二个战术效果 |
| 4 星以上 | 长期内容，首个切片不实现 |

工厂专长通过设施派驻生效，例如提高对应产能、增加仓库容量或解锁加工配方。
派驻不得阻止玩家使用喜欢的角色参与主线；同一角色只能强化一个设施。

## 战斗内伤害与无损结算

- 实时 HP、阵亡表现和主动撤退只影响当前战斗结果与复盘；
- 胜利、失败、撤退和重复结算都不得降低永久角色状态或创建维修订单；
- 结算页展示真实本局伤害、击破、失败原因与下一成长建议，但不把伤损转化为跨局税；
- 旧存档中的 readiness、injury 和 repair order 只用于迁移归一化，不进入当前战力或资源预算。

## 工厂设施

首个切片采用可点击的 3D 固定地块布局，不做自由摆放和复杂道路物流。新档只预建指挥中心，
其余固定地块先由主线事件获得修复/建造资格，再由玩家支付资源落成 Lv.1；资源不能越过进度门禁。
旧存档迁移规则由技术设计确定。建筑不是列表入口：
玩家从斜俯视工厂岛直接识别空地、建造、选择并管理建筑；选中地块必须高亮，建造状态和建筑等级
必须在世界空间可见。
资源建筑各自累计产出，建筑上方显示可领取数量，点击建筑即可只收取该建筑的资源，不重置其他
资源建筑的生产时间。功能建筑点击后打开对应管理卡。

| 设施 | 主要产出或职责 | 关键升级行为 |
|---|---|---|
| 指挥中心 | 全局等级上限与功能门禁 | 解锁设施等级、角色等级和新城区 |
| 马桶兵工厂 | 根据已解锁图纸生产基础兵种 | 增加队列、缩短时间、开放兵种分支 |
| 陶瓷厂 | 自动生产陶瓷 | 提高产速、容量和离线储存 |
| 零件车间 | 加工机械零件 | 解锁高级升级与武器维修配方 |
| 能源站 | 自动生产污水能源 | 提高生产/维修可持续时间 |
| 维修中心 | 恢复角色战备度 | 增加维修槽、提高速度、降低损耗 |
| 研究所 | 技能、星级和工业科技 | 解锁技能节点与设施质变 |
| 仓库（P0.5） | 资源容量和溢出保护 | 延长安全离线时间 |

设施升级同时包含数值成长和功能节点。关键等级必须解锁新的选择，例如第二维修槽、批量加工、
自动收取或新的研究节点；不能所有等级都只是 `+5%`。

## 经济结构

### 工业资源

- **陶瓷**：基础兵生产、角色升级、补员和常规维修；
- **机械零件**：武器、装甲、高级技能和设施加工；
- **污水能源**：生产、维修、研究和特殊角色成长。

主要由工厂设施持续生产或加工。它们是玩家的时间产能，不是体力；资源不足不能禁止玩家查看或
尝试关卡，但会限制修复和成长效率。

### 战争资源

- **金币**：角色等级、设施升级与常规研究；
- **角色经验**：出战角色成长；
- **工业技术**：设施功能解锁与等级上限；
- **技能芯片/联盟残骸**：技能与高级研究。

主要由城镇胜利、精英目标和任务获得。

### 突破资源

角色碎片、Boss 核心、章节许可证等主要来自首通、Boss 和里程碑，用于升星、解锁角色或重大设施。
它们不能由最低级挂机产能无限制造。

### 经济不变量

- 同一种资源不能在同一闭环中稳定“投入少、产出更多”；
- 工厂资源主要支持永久成长与扩建，战争资源主要支持突破；
- 不设置主线体力、扫荡券或每日挑战次数；
- 首局基础图纸由主线确定性解锁，不进入随机材料混池；
- 旧马桶钻、付费图纸抽取和真实支付退出当前范围；下一阶段可使用游戏内招募券招募永久英雄。

### 长期进度层

- 行动任务引导玩家执行已解锁的自然行为，不锁主线；
- 指挥官等级承担账户进度与渐进解锁，不直接增加战斗乘区；
- 28 天战役战令首期只有 30 级免费轨；
- 永久成就记录战役、工厂、军团、成长和收藏里程碑；
- 信号招募只产永久英雄或英雄数据，Gman 和通关必需职责由主线确定性提供；
- 五套系统共享原始玩法事件和 exact-once 奖励账本，领奖事件不得互相产出价值。

详细事件、解锁、概率和奖励预算见
[KM:reference.meta-progression-system](meta-progression-system.md)。

## 城镇与战斗

### 城镇状态

- **未侦察**：只展示轮廓与章节目标；
- **可进攻**：展示敌情、推荐战力、预计伤损和奖励；
- **已占领**：开放下一城镇、设施上限或少量被动税收，可重玩但不自动推图。

### 阵容

- 最多六名永久角色，保持前后 `2×3` 布阵；
- 空槽允许出战，但不会生成隐藏单位；
- 每名角色拥有清晰职责与可读克制；
- 战区关卡详情必须展示当前战备度和带伤出战影响。

### 三段式攻城

1. 城市外围：快速建立推进与规模感；
2. 联盟防线：引入关卡机制和明显伤损压力；
3. 基地核心：巨炮或结构机制制造高潮和撤退抉择。

战斗仍采用低频确定性领域 tick；3D 破坏、弹道、镜头震动和音效只投影领域事件，不反向决定结果。

### 结果

- 胜利：金币、经验、工业技术/战利品、进度和伤损；
- 失败：无完整通关奖励，保留少量实战经验与更准确情报，承受较高伤损；
- 撤退：无完整通关奖励，保留较低伤损，可选少量战场回收；
- 所有结果必须 exact-once，重复结算不得重复发奖、加经验或叠加伤损。

## UI 与 UX 合同

### 顶层导航

首期只保留四个稳定入口：

1. **工厂**：资源、设施、派驻和维修；
2. **军团**：角色、等级、星级、技能和阵容；
3. **战区**：章节地图、城镇情报和出征；
4. **目标**：行动任务、免费战令、永久成就和长期反馈。

### 工厂首页

玩家一眼必须看见：

- 六栋具有不同轮廓、名称、等级和点击区域的 3D 建筑；
- 当前三资源数量、每分钟产量和存满时间；
- 正在维修的角色与完成时间；
- 当前最主要瓶颈；
- 一个主 CTA 和最多两个次级建议；
- 可领取、可升级、资源不足和容量将满的状态差异。

首期建筑交互为“点击建筑 → 立即执行最常用动作或打开专属管理卡”：陶瓷厂、零件车间和能源站
点击即收取对应资源；指挥中心展示全局升级，维修中心进入整备，研究所进入角色与技术研究。

跨屏信息层级、组件状态和 844×390 验收以
[SLG UI 视觉刷新规格](../../../design/ux/slg-ui-visual-refresh.md) 为准。

### 战区关卡详情

章节/城镇地图与选中关卡详情同屏展示。详情必须显示推荐战力、主要威胁、预计伤损、首通奖励、
角色战备度和“立即出击”按钮；不设置独立战前会议或二次确认页。手机横屏 844×390 下不能依赖横向滚动。

### 战斗 HUD

保留阶段、推进、敌方核心、角色战备预警、技能与撤退。HUD 不展示全部工厂经济，避免遮挡战场。

### 结算页

先展示战争结果，再展示净成长与伤损。主 CTA 由状态决定：

- 可安全继续：`进攻下一城镇`；
- 伤损较重：`快速整备`；
- 战败：`查看原因并维修`；
- 有关键升级：`立即升级`。

结算必须能直接进入维修或下一关，不强迫玩家先返回营地。

## 首个 20–30 分钟切片（v3）

### 内容

- 唯一初始英雄：Gman；
- 三个可单人通过的教学城镇与一个首次必败、可反攻的 1-4；
- 指挥中心、科技树、马桶兵工厂与后续建筑锁定地块；
- 一张确定性基础马桶兵图纸；
- 三名教学前排小兵及生产队列；
- 独立英雄位、三个初始前排与三个渐进解锁后排；
- 一次被解释为兵力需求的无惩罚首败；
- 一次由工厂生产改变结果的 1-4 反攻。

### 玩家旅程

1. Gman 单人攻克 1-1、1-2、1-3，建立英雄强度信心；
2. Gman 在 1-4 被重炮墙稳定击败，并明确看见“缺少前排兵力”的原因；
3. 返回工厂，恢复科技树并确定性解锁基础马桶兵图纸；
4. 修复马桶兵工厂，亲手下达并领取第一名基础小兵；
5. 解锁编队，把小兵放入三个初始前排之一；
6. 通过教学加速补齐三名前排，理解图纸、建筑、生产和编队的关系；
7. 带队反攻并攻克 1-4，预告后排阵位与下一兵种。

详细节奏、门禁、防卡死和验收见
[Gman 首局 30 分钟新手阶段 v3](../../../design/ux/gman-first-30m-onboarding-v3.md)。

### 试玩必须回答

- 玩家能否复述“图纸决定兵种、建筑负责生产、编队决定上场”？
- 玩家是否理解 Gman 是英雄、基础马桶兵是工厂生产的部署单位？
- 玩家在 1-4 首败后是否主动想到需要增援，而不是刷等级或付费？
- 玩家是否理解建筑先由进度取得资格，再支付资源建造？
- 玩家能否说出三前排的作用，并期待后排与第二兵种？
- 反攻胜利是否让玩家感到工厂真正改变了战争结果？

## 当前不做

- 随机抽取基础兵图纸或用付费直接解锁兵种；
- 自动扫荡或自动首次推图；
- 可永久删除的核心角色；
- 自由建造、道路和复杂物流；
- 多队大地图、PvP、公会和排行榜；
- 装备随机词条、套装和多层角色养成；
- 马桶钻图纸材料混池、付费抽取、真实充值与广告；
- 主线体力、每日次数和 FOMO 日常。

## 平衡假设

- 单关目标 45–75 秒；
- 工厂基础容量覆盖 8–12 小时普通离线；
- 常规胜利后的快速整备成本不超过该阶段约 10–20 分钟基础产能；
- 严重失败需要更长恢复，但不能超过一次正常离线周期；
- 玩家每 2–3 场应获得一次角色或设施的可见提升；
- 首轮数值必须由确定性模拟和真人试玩共同验证，文档中的比例不是最终平衡。
- 战力、资源价值、推进能力、维修压力与内容寿命统一使用
  [KM:reference.game-state-measurement-framework](game-state-measurement-framework.md)，不得各系统私建汇率。

## 发布边界

当前项目使用 Skibidi Toilet 角色、名称和世界观做本地设计与同人原型。商业部署前必须获得覆盖
角色、名称、世界观、素材和商业运营的书面授权，并完成发行、支付、未成年人保护、隐私和素材来源审查。

# 目标、卡点与跨坎奖励阶梯

## 玩家可见目标层级

任何时刻只突出一条因果链，不把三层目标做成三个互相竞争的任务列表：

| 层级 | 时间尺度 | 玩家问题 | 首章示例 |
|---|---|---|---|
| 大目标 | 15–30 分钟 | 我为什么继续玩？ | 摧毁灰镜核心，完成第一章 |
| 中目标 | 2–8 分钟 | 这一段要证明什么？ | 研究突破、带队反攻、工业备战与选择成长 |
| 小目标 | 10–90 秒 | 我下一步点什么？ | 挑战 1-4、启动十连、把装甲放进前排 |

目标中心按“大目标 → 中目标 → 小目标 → 当前坎 → 过坎办法 → 唯一主 CTA”呈现。小目标只认
领域结果，不以“打开页面”“点击页签”或重复领奖作为进度。长期日周任务在首章之外承担习惯组织，
不得抢占当前行动的视觉优先级。

首章行动完成时，完成状态与奖励状态保持独立幂等记录，但由触发完成的同一个领域命令自动结算；
结算页用“行动完成 · 奖励已自动入账 → 新目标”回显因果链。玩家不需要额外进入目标页或点击领奖，
下一主 CTA 必须直接指向新的真实动作。

## 卡点阶梯

| 卡点 | 频率 | 作用 | 恢复预算 |
|---|---|---|---|
| 小坎 | 30–120 秒一次 | 教会一个反馈或操作 | 立即重试、一次技能或一次明确提示 |
| 中坎 | 3–8 分钟一次 | 要求一次编队或成长决策 | 1–3 个可执行动作，资产不损失 |
| 大坎 | 每章 1–2 次 | 改变玩家理解或形成高潮 | 明确失败原因、保障资源、确定性逆转路线 |

首章的大坎一是 1-4 首败：单人职责不足；恢复链为首败战报 → 70 保障币 → 建研究所 →
免费研究突破十连 → 两名永久援军 → 三人反攻。大坎二是 1-5：基础三人不稳定；恢复链为读取
Boss 巨炮 → 任选资源设施投产并收取验收后勤 → 在冲锋/装甲二星中自主选一条 → 再战。
新设施按真实 L1 每分钟产速预置一次验收批次，玩家能立即完成首轮收取，不用挂机等进度。
Boss 预警给出两种可辨认的过坎办法：冲锋集中爆发打断，装甲开盾承炮并反震核心；成长选择
必须改变玩家操作与战斗反馈，而不只是提高同一个 CP 数字。
失败不会删除角色、扣除永久战力或制造等待。

1-4 属于必须先亲自观察的信息战，因此情境目标优先于通用能力比建议：首遇只能引导试探，不得
因为能力比极低就提前显示“先培养军团”。第一次结算记录真实尝试后，通用成长路由才可接管，
并且只能指向已经通过战报揭示的研究所与永久援军方案。

大坎恢复链的每一步都必须可从存档重建，不能只存在于上一张结算页：研究所未建时指向建造，
研究所已建但未突破时指向免费十连，永久援军已领取但未上阵时指向编队，两种职责均上阵后才
释放反攻。通用战力建议只能在没有更具体、可执行的情境行动时作为兜底。

卡点不是付费拦截器。若非付费玩家在设计时间窗内没有至少一条确定性恢复路径，则属于经济或关卡
缺陷，不允许用礼包、抽卡弹窗或任务文案掩盖。

## 研究突破十连

研究所落成后提供一次账号/存档级免费十连：

- 恰好展示十张结果；
- 固定包含 A 级冲锋与装甲两名永久援军；
- 其余八张是 1 枚技能芯片和首章可用工业资源；
- 不消耗招募券，不推进或重置长期招募 A/S 保底；
- 用 durable command receipt 和稳定 claim key 防止重复发放；
- 结果页直接指向编队，形成“失败原因 → 新能力 → 立即验证”的闭环。

这是对跨过大坎的庆祝和长期招募系统的低风险预览，不是假随机诱导。正式招募仍在首章完成后开放，
必须公开概率、保底和重复转化；不得在首败后立即出售战力解法。

十连完成后的 UI 使用专注结果态，不让蓝图树、长期分支和奖励同时竞争注意力：两张 A 级援军卡
优先解释“冲锋快速突破、装甲承伤保护”，八张工业资源卡作为次级结果，标题明确“高墙解法已到位”，
唯一主 CTA 为“立即编入反攻队”。短胜利音效和依次揭晓 Tween 用来匹配大坎奖励的重要性；减少
动态模式直接呈现最终状态，文字、形状和颜色仍完整表达结果。该设计遵循 Apple HIG 对反馈强度
匹配事件重要性、多通道反馈、短而精确动效和动效可选的要求。

“立即编入反攻队”不是把玩家丢进完整六槽管理页。首次进入时只保留三个前排槽、当前候选和
`0/2 → 1/2` 进度：先推荐装甲承伤，再推荐冲锋压制；每次仍由玩家亲自选择并提交领域命令。
完成两次真实上阵后立即提供 1-4 反攻，不再要求返回基地、打开战区或寻找任务入口。这样保留
“我组建了队伍”的能动性，同时把纯导航和重复选槽从大坎恢复链中移除。

反攻不能只在后台改变胜率。战斗开场先用“装甲承伤、冲锋压制”把新职责投射到当前局；结算再
使用真实战斗统计对比“单人首败 → 三人反攻成功”，显示援军承伤和输出占比。玩家因此能把
研究、编队和胜利连成因果，而不是把胜利误解成系统放水。统计只解释本局，不承诺固定占比。

反攻后的工业备战使用“建资源设施 → 收取投产物资 → 二选一永久成长”连续链。任务 CTA 必须
进入当前所需的具体状态，不能回到同一任务页形成导航死循环。首次二星选择只并列展示两条已验证
路线：冲锋强调快速压制巨炮，装甲强调格挡反震与容错；二者同时给出本局目标、`ΔCP` 和精确
成本，保留玩家决定权。其他成员、招募、派驻和技能研究在本次决定完成前延后显示。

首次成长不是在“升星成功”处结束，而要立即兑现为一次验证机会：成功提交后保留所选路线语境，
给出 5 秒巨炮操作窗口并直达 1-5。失败恢复按权威事实分流：缺二星属于成长坎；有二星但被巨炮
命中属于机制/时机坎；成功压制巨炮仍失败属于阵容/战力坎。每种只给匹配的主行动，避免用通用
“再来一次”或同时展示工厂、军团、战区三个出口稀释学习。

首章 Boss 胜利承担大目标兑现，而不是继续制造养成缺口。结算先证明所选路线如何处理了巨炮，
再回显首章行动完成和实际系统解锁，最后给出一个可理解但不强迫连续战斗的下一目标：侦察 2-1。
三星、工厂扩建和 Meta 入口可以作为次级自由选择，但不能取代“首章完成 → 新战线开放”的主叙事。

侦察 2-1 后必须把章节间战力断层翻译成新的目标，而不是只留下一个高风险“立即出击”。当编队
低于挑战线时，战区突出“先培养军团”并保留“仍要试探”；目标中心将大目标更新为推进第二章，
中目标更新为突破震荡封锁线，小目标显示到挑战线的真实缺口。过坎说明必须明确首章资产全部保留、
存在非付费成长路线。玩家达到挑战线后，主行动再切回侦察/进攻，避免永久拦截探索。

这一目标链不能依赖玩家连续在线。退出并恢复后，标题摘要、基地前线来电、目标中心和战区侦察
必须从同一关卡与同一 `WarReadinessReport` 投影缺口和主行动；任何入口都不得重新显示已完成的
新兵训练、回到旧章节，或绕过风险判断直接开战。

## 商业化假设与边界

目标是提高玩家对角色收集、差异化阵容和长期成长的兴趣，而不是制造焦虑。可以在真人测试中验证：

1. 十连揭晓是否被玩家视为“我解决了问题后的奖励”；
2. 玩家能否说出冲锋和装甲分别解决什么；
3. 玩家在 1-4 反攻后是否愿意了解更多角色；
4. 玩家是否理解免费突破十连与长期招募保底互不影响；
5. 若移除任何付费入口，首章是否仍完整、顺畅且可达。

上线前商业化门禁：概率与保底法务文本、未成年人和地区合规、价格梯度、退款与恢复、付费前后
胜率差异、非付费 7/30 日可达性，以及至少五名目标玩家的无引导理解证据。

# 手机端随机英雄放置远征

本仓库正在规划和制作一款 Godot 4.7.1 手机端单机休闲放置游戏。核心体验是随机英雄培养、四人编队、挂机刷宝，以及通过成长跨过此前失败的关卡。

当前状态：产品与技术规划已经批准，游戏子项目 `game/` 尚未开始实现；现有 `project-a/` 是独立的 Godot AI 插件工程，不属于游戏实现范围。

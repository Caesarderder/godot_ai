# 手机端随机英雄放置远征

本仓库正在制作一款手机端 Web-first 3D 单机休闲放置游戏。当前核心体验是马桶人工厂生产、同原型同星 3 合 1 培育、六人 2×3 编队、三阶段自动攻城，以及通过生产和升星跨过此前失败的关卡。

当前开发根是 `project-a/`：Godot 4.6.3、GDScript、3D 表现、Web-first 发布，主要运行在手机浏览器。`taptap/` 保留为历史可玩原型和产品参考，不再承接当前版本交付。

`project-a/` 已使用 GL Compatibility，并已落地 v2 可玩切片：8 个初始马桶人、三材料八配方工厂、最多 3 个生产订单、生产领取生成永久英雄、同原型同星 3 合 1 升星、六槽编队、5Hz 三阶段 3D 攻城、主动/自动技能、核心巨炮和一次性结算。单线程 Web release preset、导出和本地 HTTP 浏览器交互已经验证；PWA、浏览器生命周期、离线结算与 Android/iOS 真机验证仍在后续里程碑中。

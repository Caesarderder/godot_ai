# 手机端随机英雄放置远征

本仓库正在制作一款手机端单机休闲放置游戏。核心体验是随机英雄培养、四人编队、挂机刷宝，以及通过成长跨过此前失败的关卡。

当前开发根是 `taptap/` TapTap Maker / UrhoX Lua 纯 2D 工程，提交、推送、预览与构建统一使用 TapTap MCP。`project-a/` 的 Godot 4.7.1 M0 完整保留为历史验证基线，不再是默认玩法落点。

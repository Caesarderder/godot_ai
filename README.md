# 手机端随机英雄放置远征

本仓库正在制作一款手机端 Web-first 3D 单机休闲放置游戏。当前核心体验是马桶人工厂生产、同原型同星 3 合 1 培育、六人 2×3 编队、三阶段自动攻城，以及通过生产和升星跨过此前失败的关卡。

当前开发根是 `project-a/`：Godot 4.6.3、GDScript、3D 表现、Web-first 发布，主要运行在手机浏览器。`taptap/` 保留为历史可玩原型和产品参考，不再承接当前版本交付。

`project-a/` 已使用 GL Compatibility，并已形成第一幕本地发行候选：8 个地球马桶人、三材料八配方工厂、3 个生产订单、3 合 1 升星、六槽编队、五章 25 关、五个基地 Boss、5Hz 三阶段 3D 攻城、主动/自动技能、章节推进与一次性结算。单线程 Web/PWA 导出、设置与失焦暂停、低中高特效、发行产物审计和 844×390 本地 HTTP 浏览器路径已经验证；生产 HTTPS、离线战斗、Android/iOS 真机、素材授权/IP 与正式上架仍是外部门禁。

# 马桶人进化-维度爆裂

本仓库正在把现有原型重构为手机端 Web-first 3D 轻量 SLG。目标核心体验是：工厂设施持续生产陶瓷、机械零件和污水能源，玩家永久培养最多六人的马桶人主力军团，主动攻占城镇获得金币、经验与工业技术，再把资源和战果投入角色与工厂的永久成长。战斗内 HP 只决定本局胜负，战后全员无损返回。

当前开发根是 `project-a/`：Godot 4.6.3、GDScript、3D 表现、Web-first，主要运行在手机浏览器。当前 schema v8 已实现永久角色、工厂后勤、五章主动攻城、持续伤损维修，以及指挥官等级、行动任务、免费战令、永久成就和游戏内招募券驱动的永久英雄招募；剩余发布与真人验证差距以知识地图的实现状态节点为准。

当前 P0 不包含量产马桶人、自动扫荡、图纸抽取、真实充值、复杂自由建造、PvP 或公会。商业部署仍必须以商业 IP 授权及目标地区发行、支付、未成年人保护和隐私合规为前置门禁。

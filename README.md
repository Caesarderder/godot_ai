# 手机端随机英雄放置远征

本仓库正在制作一款手机端单机休闲放置游戏。核心体验是随机英雄培养、四人编队、挂机刷宝，以及通过成长跨过此前失败的关卡。

当前开发根是 `project-a/` Godot 4.7.1 工程，后续玩法、界面、测试与构建都以该工程为默认落点。`taptap/` TapTap Maker / UrhoX Lua 纯 2D 原型完整保留，作为已验证的玩法与表现参考，不再承接默认开发。

# 制作人知识地图

Choose one available entry:

- [阶段](stages.md)
- [实践](practices.md)

After choosing a leaf, consult [templates](templates.md), [protected owners](protected.md),
[cross-role routes](routes.md), [ownership](ownership.md), [constraints](constraints.md), or
[invariants](invariants.md) only when that leaf requires them.

Use [the generated legacy index](../references/indexes/legacy-path-map.md) only to resolve an old
name. 类型与系统请求必须 handoff 给拥有该结果的岗位，不能进入空轴或把 legacy index
当作兜底搜索。

A one-line request to make, create, build, start, or continue a game in an empty or near-empty
project starts at `stage -> game-prototype`. The user does not need to name the role or leaf.
The same verbs in an existing concrete implementation, debug, asset, audio, test, Web build, or
release request do not select producer.

Contract creation, semantic scope change, cross-role drift, and milestone acceptance select
`practice -> game-project-contract`; ordinary isolated fixes do not.
A general new-game request starts only on the stage axis. Contract setup is a delayed follow-on after
the product spine, not a second initial axis.

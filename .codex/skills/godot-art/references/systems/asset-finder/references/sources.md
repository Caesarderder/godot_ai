# Asset Finder source registry

Only sources listed here are enabled. Each asset pack still requires a per-download license check.
Do not infer permission from availability or from this registry alone.

### Kenney search procedure

1. Translate the user's need into English catalog terms and synonyms.
2. Search `https://kenney.nl/assets` and, when useful, a domain-restricted query for
   `site:kenney.nl/assets <terms>`.
3. Open each candidate's official asset page; do not use third-party mirrors or marketplace
   repackages.
4. Confirm category, file count, formats, pack-specific license display, and whether it contains a
   ready-made map or only reusable tiles/sprites.
5. Download only the chosen pack through the official free path.

### Example: 2D farm map request

Search terms may include `farm`, `farming`, `top-down`, `tiles`, `terrain`, `nature`, `crops`,
`buildings`, and `map`. Prefer a pack that matches the project's perspective and tile scale. If
Kenney offers only farm tiles or sprites, report that accurately and use them to support map
construction rather than describing them as a finished map.

# Art Direction and Asset Production

## Art direction brief

只记录当前可玩范围真正需要的约束：视觉命题、形状语言、材质/光影、色彩语义、比例与镜头、动效能量、禁止项，以及 2–4 个能被实际画面验证的基准场景。参考图用于解释特征，不等于可直接使用的资产或已获得许可。

## Asset contract

| 字段 | 内容 |
| --- | --- |
| 语义名称 | 对应的玩法对象或状态 |
| 用途/场景 | 何时、从什么视角出现 |
| 类型 | 复用、变体、独有、占位或暂缓 |
| 技术约束 | 尺寸、比例、透明、轴心、循环、状态、性能预算 |
| 视觉约束 | 轮廓、材质、色彩角色、光向、视觉重量 |
| 来源 | 作者、生成/采购来源、许可证和归属要求 |
| 验收画面 | 必须在哪个实际运行状态中检查 |

先复用能维持视觉语言的基础件，再生产会影响识别、决策或招牌时刻的独有资产。不要用资产数量作为进度门槛。

## Audit

审查清单：文件能被 Godot 当前导入；引用不缺失；状态/方向/帧覆盖完整；尺寸和轴心正确；透明边缘无污染；缩放与目标分辨率可读；许可证可追溯；真实画面中不遮挡玩法；与现有语言一致。将结果分为 `已在运行画面验证`、`仅导入验证`、`仅文件检查`、`未知`。

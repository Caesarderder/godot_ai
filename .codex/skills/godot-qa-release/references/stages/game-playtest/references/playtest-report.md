# Playtest evidence template

```markdown
# Playtest: <build> — <date>

## Question
- Hypothesis:
- Audience and participant context:
- Build / browser / device / input / locale:
- Start state and timebox:
- Limitations or interventions:

## Observations
| Time | Observed behavior | Outcome |
| --- | --- | --- |

## Participant interpretation
- Goal as understood:
- Decision reasons:
- Confusing or surprising moments:
- Desired next action:

## Analysis
- Supported evidence:
- Contradicting evidence:
- Analyst inferences:
- Alternative explanations:

## Decision
- Verdict: supported / contradicted / mixed / not tested
- Highest-value change:
- Deferred findings:
- Next hypothesis and re-test:
```

Keep raw notes or recordings only when consent and project policy allow it. A report without an actual session must be labeled `planned`, not `completed`.

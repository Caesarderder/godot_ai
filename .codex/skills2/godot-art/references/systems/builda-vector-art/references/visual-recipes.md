# Vector Visual Recipes

## 统一视觉语言

先定义一个最小 token 集：

```text
outline: 主轮廓色
surface: 主体色
highlight: 高光色
accent: 行为或稀有度强调色
danger: 伤害和危险色
muted: 阴影与非激活状态
stroke: 同一资产族的基准描边宽度
```

同一资产族共享 outline、stroke 和高光方向。通过轮廓、比例、主色和一个语义特征区分成员，避免只换颜色。

## UI 图标

- 在 32、48 或 64 方形网格中设计。
- 保留约 10% 安全边距。
- 先画能表达含义的主轮廓，再加最多两个内部特征。
- 普通、悬停、按下和禁用状态优先由 Godot 的 modulate、缩放和主题颜色产生；只有轮廓确实变化时才生成多份 SVG。
- 动态数值、中文和快捷键提示使用 `Label`，不要写入 SVG。

## UI 面板与卡片

- SVG 只画边框、底色、切角和少量角部装饰。
- 中心区域保持可拉伸，重要装饰远离拉伸区。
- 在 Godot 中使用 `StyleBoxTexture`，texture margins 对应不可拉伸的边缘厚度。
- hover 可以复用同一纹理并叠加亮度、描边或微缩放；pressed 使用更暗底色和更紧凑的缩放。

## 单图角色与敌人

- 用强剪影表达职业或行为：重装更宽、快速单位更尖、更低，远程单位突出发射器官。
- 眼睛和面部特征保持简单，让低分辨率仍可读。
- 脚底半透明椭圆可以提供落地感，但场景已有统一阴影系统时不要重复绘制。
- 把武器拆为独立 SVG，便于瞄准、后坐力、换装和枪口定位。
- 用整体 bob、tilt、squash/stretch 和 hit flash 提供基础生命感。

## 分件角色

需要转身、攻击或更丰富待机时拆分：

```text
character_id/
├── body.svg
├── head.svg
├── upper_arm_left.svg
├── forearm_left.svg
├── upper_arm_right.svg
├── forearm_right.svg
├── weapon.svg
└── accessory.svg
```

- 各分件保持相同总体坐标约定和明确连接点。
- 在 Godot 节点上设置 pivot，不依赖 SVG transform-origin。
- 被遮挡连接处预留重叠，避免旋转后露缝。
- 左右件只有视觉不对称时才生成两份；否则在 Godot 中翻转复用。

## 武器和弹丸

- 武器默认朝右，枪口或攻击端落在稳定的局部坐标位置。
- 轮廓必须比内部结构更显著，缩小后仍能识别武器类别。
- 弹丸的长轴沿 X 轴，方便按速度方向旋转。
- 用形状区分伤害语义：穿刺细长、爆炸宽重、能量圆润、火焰具有后掠尾部。

## VFX 图元

SVG 只提供一帧清晰形状：

- 枪口：锥形或星芒；
- 命中：碎片、十字星、冲击环；
- 死亡：放射爆裂、烟尘团；
- 冲刺：环、弧线、短拖尾；
- 拾取：晶体、光点、徽记。

在 Godot 中通过缩放、旋转、透明度、颜色和散射产生时间变化。不要为连续动画生成大量近似 SVG 帧。

## 背景与场景装饰

- 全屏背景可以使用少量大形状建立色带、地貌层次和装饰点。
- 可交互场景元素应独立成文件，不要烘进背景。
- 避免数百个微小装饰；程序化分布应由 Godot 完成。
- 背景 SVG 在导入后仍会成为纹理，控制目标画布和 import scale。
